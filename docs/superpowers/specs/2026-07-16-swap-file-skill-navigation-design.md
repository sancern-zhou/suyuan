# 文件管理与技能管理位置交换设计

## 目标

交换左侧导航中的“文件管理”和“技能管理”位置，使技能管理成为固定主导航入口，文件管理进入左下角用户设置展开菜单。

## 交互与布局

- 固定主导航保持现有顺序，仅将“文件管理”替换为“技能管理”。
- 用户设置菜单保持现有顺序，仅将“技能管理”替换为“文件管理”。
- 模块名称、图标、路由和点击行为作为整体移动，不修改各模块自身功能。
- 其他入口、间距、滚动方式及选中态保持不变。

## 实现方式

调整 `AssistantSidebar.vue` 中主导航模块 ID 列表和设置菜单模块 ID 列表，不复制模块定义，也不通过交换显示文案伪造位置变化。

## 验证

- 自动化测试确认技能管理属于固定主导航。
- 自动化测试确认文件管理属于用户设置菜单。
- 现有智能体平台集成测试全部通过。
- standalone 前端构建成功。
