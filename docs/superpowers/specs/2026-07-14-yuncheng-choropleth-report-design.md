# 运城市污染物分布图纳入告警溯源报告设计

## 目标

将已抓取的 `city_pollutant_choropleth.png` 正式纳入运城市告警溯源分析 Skill，确保图片存在时不只出现在 manifest 或附件清单，而是在最终报告正文中展示并参与周边联动分析。

## 范围

本次只修改以下 Skill 约束：

- `backend/docs/skills/yuncheng_alert_tracing_skill.md`
- `backend/docs/skills/routine_monitoring_analysis_expert.md`

不修改图片生成、抓取和 manifest 写入逻辑；现有抓取流程已经能生成并登记该资产。

## 资产职责

`city_pollutant_choropleth.png` 归常规分析专家主责，用于展示告警目标污染物在运城市与周边城市之间的空间分布，辅助判断区域同步抬升、局地偏高或混合影响。

常规分析专家必须读取目标城市小时数据、周边城市小时数据及 manifest 中该图片对应的请求参数，用相同污染物和尽可能一致的有效时次解释图片。图片不得单独用于确认污染来源。

## 展示规则

只要 `city_pollutant_choropleth.png` 存在：

1. 常规分析草稿必须插入相对路径图片引用 `![城市污染物空间分布](city_pollutant_choropleth.png)`。
2. 最终 `report.qmd` 必须在“污染过程时间线”的周边联动节点，或该节点内的“周边联动”内容中展示图片。
3. 图片不得仅列在“附件与数据来源”中。
4. 图注必须写明实际有效时次、目标污染物、运城市与周边城市的主要空间差异，以及该差异对现场盯守的业务意义。
5. 图片只支持区域分布和联动判断，不得据此确认具体污染源或责任主体。

若图片缺失，不生成空占位；常规分析草稿和最终报告应在“需要补充确认的信息”中说明缺失及其对区域联动判断的影响。

## 主 Agent 验收

主 Agent 在生成 Word 前必须检查：

- 图片存在时，常规分析草稿包含 `city_pollutant_choropleth.png` 引用；
- 图片存在时，最终 `report.qmd` 包含 `city_pollutant_choropleth.png` 引用；
- 最终报告中的引用位于污染过程时间线或周边联动正文，而非仅在附件清单；
- 图片附近具有满足展示规则的业务化图注。

任一检查不满足时，应补齐草稿或最终报告后再导出 Word，不得直接通过验收。

## 验证方式

实施后进行只读文本校验：

- 主 Skill 的专家资产分工表包含该图片及常规分析专家职责；
- 常规分析专家 Skill 的运城资产要求表包含该图片和强制插图要求；
- 主 Skill 的最终报告生成与验收步骤包含“存在即必须正文引用”的规则；
- 原有其他资产要求和业务边界保持不变。
