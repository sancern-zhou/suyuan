# 侧边栏固定导航设计

## 目标

让会话历史、知识管理、文件管理、定时任务与智能体平台、新建任务一样固定在左侧面板，不随最近对话列表滚动。

## 布局结构

侧边栏从上到下分为五个区域：

1. 品牌与折叠按钮。
2. 智能体平台、新建任务。
3. 会话历史、知识管理、文件管理、定时任务。
4. 占用剩余高度并独立滚动的最近对话或案例库。
5. 固定在底部的用户信息与设置菜单。

## 实现方案

- 将 `.module-list` 从 `.sidebar-scroll-area` 中移出，放在新建任务区之后。
- 使用 `.primary-navigation` 将智能体平台、新建任务和后四个功能入口包裹为一个连续的固定导航区域。
- `.primary-navigation`、`.new-session-section`、`.module-list` 和 `.module-group` 的垂直间距统一为 `4px`，并删除两组入口之间原有的底部内边距与外边距，保证任意相邻按钮间距一致。
- 将 `.sidebar-scroll-area` 改为只包含最近对话区域。
- `.sidebar-scroll-area` 保持 `flex: 1`、`min-height: 0` 和纵向滚动，确保历史列表只在自身区域滚动。
- `.module-list` 设置为不可压缩的固定导航区域，并保留现有功能顺序与点击事件。
- 用户设置底栏继续作为不可压缩区域固定在最下方。
- 侧边栏收起时，固定导航的四个图标继续显示；最近对话区域按现有逻辑隐藏。

## 行为边界

- 不改变四个功能入口的名称、顺序、图标和管理面板逻辑。
- 不改变六个入口既有的按钮高度、左右内边距和激活状态。
- 不改变最近对话与案例库切换行为。
- 不改变用户设置菜单和侧边栏折叠行为。
- 最近对话为空时，剩余空间保持为空，不拉伸固定入口。

## 测试与验收

- 源码回归测试确认 `.module-list` 位于 `.sidebar-scroll-area` 之前，而最近对话位于滚动区域内部。
- 测试确认六个入口位于同一个 `.primary-navigation` 中，并且所有相关容器使用统一 `4px` 间距，不再包含组间底部留白。
- 测试确认滚动属性只应用在 `.sidebar-scroll-area`。
- standalone 构建成功后，在 1440×900 和 1920×1080 下填充足够的历史会话并滚动到底部，验证六个主入口的纵向位置保持不变。
- 验证最近对话列表能够独立滚动，用户底栏始终可见。
- 验证折叠侧边栏后六个入口图标仍可见。
- 在展开与折叠状态下测量六个入口的相邻纵向间隔，确认全部一致。
