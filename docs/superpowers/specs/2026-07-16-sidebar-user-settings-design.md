# 侧边栏用户设置菜单设计

## 目标

将工具管理、技能管理、数据管理、社交管理从左侧主功能区迁移到左下角用户设置菜单，降低主导航密度，同时保留原有管理面板能力。

## 页面结构

- 左侧栏继续保留智能体平台、新对话、会话历史、知识管理、文件管理和定时任务等主入口。
- “系统”分组只保留定时任务。
- 侧边栏底部新增固定用户标签，不随中部导航和最近对话滚动离开视口。
- 用户标签左侧只显示一行用户名称，右侧显示线性齿轮设置按钮。
- 设置菜单锚定用户标签并向上展开，依次包含工具管理、技能管理、数据管理、社交管理。

## 用户信息

用户名称读取顺序为：

1. `auth.user.name`
2. `auth.user.userName`
3. `当前用户`

展开侧边栏时显示完整单行名称，超出宽度时省略。收起侧边栏时使用名称首字作为紧凑头像标识，并保留齿轮按钮。

## 交互

- 点击齿轮切换设置菜单的展开与收起。
- 设置按钮提供 `aria-expanded` 和 `aria-controls`。
- 菜单使用菜单语义，每个入口保持可聚焦按钮。
- 点击菜单项复用现有 `action` 事件打开对应管理面板，并自动关闭菜单。
- 点击组件外部或按 Escape 关闭菜单。
- 侧边栏折叠状态变化时关闭菜单，避免悬浮层残留。
- 收起侧边栏时菜单向右上方展开，避免被窄栏裁切。

## 数据与组件边界

- `AssistantSidebar.vue` 通过现有 `useAuthStore` 读取用户，不新增父组件参数。
- 四个设置入口继续复用现有 `modules` 元数据、图标和 `handleModuleSelect` 事件链路。
- 新增 `settingsModules` 计算结果用于设置菜单。
- `moduleGroups` 的系统分组只包含 `scheduled-tasks`。
- 不调整 `MainLayout.vue` 中管理面板的渲染与事件处理。

## 样式

- 用户标签采用与现有侧栏一致的浅色背景、细分隔线和简洁悬停状态，不使用强调色大按钮。
- 设置菜单为轻量白色浮层，使用细边框和柔和阴影。
- 菜单项沿用主导航图标尺寸与文字层级。
- 底部区域固定占位，中部 `module-list` 与最近对话区域保留可滚动空间。

## 测试与验收

- 测试确认四个管理入口不再属于 `moduleGroups` 的系统分组。
- 测试确认 `settingsModules` 顺序为工具、技能、数据、社交。
- 测试确认用户名称回退逻辑以及设置按钮的无障碍属性。
- 测试确认菜单项仍调用 `handleModuleSelect`，点击后关闭菜单。
- 测试确认 Escape、外部点击和侧栏折叠能够关闭菜单。
- standalone 构建成功后，在 1440×900 与 1920×1080 下验证底部用户标签可见、菜单不被裁切、原管理面板均可打开。
