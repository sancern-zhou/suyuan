# 排污许可证生产经营场所地址入库设计

## 目标

将许可证详情页标题区域中的“生产经营场所地址”按页面原文结构化保存，并回填已经完成试跑的许可证记录。

## 设计

- 在 `permit_licenses` 增加可空文本列 `production_site_address`。
- `PermitDetail` 增加同名属性，详情解析器从“生产经营场所地址：”至下一个标题字段之间提取地址，解码 HTML 实体并压缩仅用于排版的空白。
- `PermitRepository.save_detail` 将解析结果写入许可证主表。页面不存在该字段时保存 `NULL`，不进行推断或地址标准化。
- 迁移脚本除创建新库表外，对已存在的 `permit_licenses` 执行幂等加列。
- 当前已完成的试跑记录从本地保存的 `detail.html` 解析回填，不重新访问平台或下载附件。

## 验证

- 固件测试断言地址解析结果为原始地址文本。
- 仓储测试断言保存详情时更新主表地址。
- 运行现有采集器测试、Ruff 和语法编译。
- 查询生产数据库确认试跑许可证地址已回填。

## 非目标

不拆分省、市、区县，不进行地理编码，不支持多个生产场所，不修改调度器、API 或前端。
