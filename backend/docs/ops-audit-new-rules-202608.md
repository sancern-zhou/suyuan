# 省控网工单新增审核规则说明

## 一、说明

本次新增规则来源于省控网每周工单审核问题的整理结果，主要补充了月度气态校准、颗粒物周检、颗粒物流量校准、臭氧量值传递和气态多点校准等场景。

新增规则分为两类：

- 确定性规则：可以直接根据工单类型、设备型号、表单字段和附件类型作出明确判断，系统可直接形成审核问题。
- 多模态识别规则：需要读取照片、截图中的界面内容、水印或站点名称。系统只在证据较明确时生成待人工复核项，不直接代替人工作出最终结论。

## 二、确定性审核规则

### 1. 月度气态校准设备检查室内湿度超范围

规则标识：RF_M_GASEOUS_CALIDEVICE_ENV_HUMIDITY_OUT_OF_RANGE

适用范围：月度动态气体校准仪检查表。

审核内容：检查作业环境中的室内湿度是否处于合理范围。湿度应在百分之零至百分之八十之间，包括上下限。

判定方式：表单中填写的湿度低于百分之零或高于百分之八十时，判定为环境湿度超出允许范围。如果湿度未填写，则由原有的必填项规则处理，本规则不重复报错。

问题级别：高。

审核目的：避免在不符合要求的环境条件下开展动态气体校准仪流量检查，降低环境湿度对检查结果的影响。

### 2. 1405 或 TEOM 设备错误填写纸带用量

规则标识：RF_PM_PAPER_TAPE_NOT_APPLICABLE_FILLED

适用范围：颗粒物周检表，且设备型号属于 1405 或 TEOM 类设备。

审核内容：检查纸带使用量及处置情况是否被错误填写。

判定方式：1405 或 TEOM 类设备使用滤膜，不使用纸带。如果纸带字段填写了实际用量、处置情况或其他实质性内容，则判定为耗材类型填报错误。字段为空，或者明确填写“无”“不适用”“无需”“无纸带”等内容时，不判定为问题。

问题级别：中。

审核目的：防止把其他颗粒物设备的纸带维护内容套用到 1405 或 TEOM 设备上。

### 3. 颗粒物流量校准状态与校准后结果不一致

规则标识：RF_PM_FLOW_CALIBRATION_STATE_MISMATCH

适用范围：两周颗粒物流量校准表。

审核内容：核对“是否校准”的选择与校准后读数是否一致。

判定方式：表单选择“未校准”或“否”，但仍填写了校准后的标准流量、仪器流量或误差等有效结果时，判定为状态与结果不一致。仅填写空值、斜杠、“无”“未校准”“无需校准”等说明性内容时，不判定为问题。

问题级别：中。

审核目的：避免出现实际填写了校准结果，但状态仍选择“未校准”的矛盾记录。

### 4. 臭氧动态校准仪量值传递报告缺失

规则标识：O3_VALUE_PASS_REPORT

适用范围：包含臭氧量值传递表的相关检查工单。

审核内容：检查工单是否上传臭氧动态校准仪量值传递报告。

判定方式：工单已经填写臭氧量值传递表，但附件中没有能够识别为量值传递报告的文件时，判定为报告缺失。报告应包含可追溯的计算数据，不能仅以现场照片代替正式报告。

问题级别：高。

审核目的：保证臭氧量值传递结果具备完整、可追溯的计算依据和报告材料。

## 三、多模态识别审核规则

### 5. 多点校准附件水印和站点名称复核

规则标识：ATTACHMENT_MULTIPOINT_WATERMARK_REVIEW

适用范围：一氧化碳、二氧化氮、臭氧和二氧化硫季度多点校准附件。

审核内容：读取多点校准图片中的现场水印日期和站点名称，确认附件能够证明作业时间、作业地点与当前工单有关联。

判定方式：当图片中明确缺少水印日期、缺少站点名称，或者图片中的站点名称与工单站点明显不一致时，生成待人工复核项。图片模糊、文字被遮挡或者模型识别把握不足时，不直接判定为正式问题。

问题级别：中，属于人工复核候选。

审核边界：本规则只核对水印日期和站点名称是否能够建立现场关联，不负责判断具体校准数值是否合格。

### 6. 臭氧初始浓度更新后六点结果复核

规则标识：ATTACHMENT_O3_TRANSFER_SIX_POINT_REVIEW

适用范围：臭氧动态校准仪量值传递工单中的校准仪界面截图和数据采集界面截图。

审核内容：检查臭氧发生器初始浓度更新后，六个传递点的结果是否已经重新计算或重新填写，防止继续使用更新前的旧结果。

判定方式：当截图能够明确显示初始浓度已经改变，但六点结果仍保留旧批次数据、部分点位没有刷新，或者六点结果未完整更新时，生成待人工复核项。证据不足时不直接认定为问题。

问题级别：中，属于人工复核候选。

审核边界：单个浓度点的实测照片和零点照片不作为六点汇总结果审核对象。该规则主要审核动态校准仪浓度设置截图和数据采集结果截图。

## 四、多模态附件筛选优化

为保证新增多模态规则能够覆盖实际附件命名方式，本次同时调整了附件筛选范围。

臭氧量值传递场景能够识别“动态校准仪”“浓度数采”等实际文件名，同时排除带有“实测”“零点”等特征的单点照片，避免把单点证据误当作六点汇总结果。

多点校准场景能够识别“O3多点”“四气态多点”等简短文件名。类似“O3多点90”这种只代表单个浓度点的照片不会作为完整多点曲线或多点记录进行审核。

对于一张图片同时包含多种气体记录的情况，审核时只查看当前工单所对应污染物的栏目，不会因为图片中同时出现其他污染物而直接判定污染物不一致。

## 五、审核结果使用说明

确定性规则命中后，可以直接作为工单审核问题输出，但审核人员仍可结合工单备注和现场特殊情况进行复核。

多模态规则命中后，输出的是“待人工复核”事项。审核人员应打开对应原始附件，确认图片内容、水印、站点和六点更新情况后，再决定是否作为最终问题反馈。

当图片无法下载、画面模糊、文字无法识别或识别结果不完整时，系统不应把技术失败等同于业务问题，而应提示资料不足或保留人工检查。

## 六、批量验证结果

本次使用实际审核样本和构造场景对新增规则进行了批量验证。

实际样本共覆盖四十二个工单、二百零二条工单明细和五百九十四个附件。颗粒物流量校准状态不一致规则在实际样本中命中一条，其余确定性规则在当前样本中未发现误报。

构造场景中，月度湿度超范围、纸带误填、颗粒物流量校准状态不一致、臭氧六点结果复核和多点附件水印复核的实际命中数量均与预期一致。

多模态真实附件复测确认，优化后模型能够返回结构化审核结果；四气态合并记录不再因为包含多个污染物栏目而产生错误的污染物不一致提示。对于图片中确实缺少水印或站点信息的情况，仍会保留人工复核提示。
