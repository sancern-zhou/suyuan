# 示例2

## 概述
用于空气质量分析中的常规监测事实梳理、AQI 口径判断、污染物变化分析、区域同步性分析和风险提示。该 skill 专注于业务知识和分析逻辑，不绑定具体城市、文件名、报告模板或子 Agent 返回格式。

## 业务知识

- 常规监测分析首先回答“何时、何地、什么污染物、达到什么程度、变化趋势如何”。
- AQI 是综合空气质量指数，不等同于任一单项污染物浓度。
- 首要污染物、分项污染物小时变化和周边城市同步性，是判断污染过程性质的基础证据。
- PM2.5、PM10、NO2、CO 同步上升常提示燃烧、扬尘或累积线索；O3 与 NO2、温度、辐射和区域输送关系需要结合气象判断。
- 周边城市同步抬升可提示区域过程，不同步则更支持本地累积或局地扰动，但都需要结合气象和本地排放信息。

## 分析逻辑

1. 明确告警污染物、AQI、污染等级、首要污染物和触发规则。
2. 梳理目标城市污染物小时变化、峰值、持续时间和告警前后趋势。
3. 对比周边城市同一时段变化，判断是否存在区域同步抬升。
4. 对 AQI 告警，优先识别首要污染物和主要贡献污染物；缺少首要污染物时只写需结合分项污染物确认。
5. 结合未来空气质量预报判断 24-48 小时风险和是否需要加密盯守。
6. 形成可执行建议时，应包含时间窗、核查范围、现场动作、补充数据和升级条件。

## 边界

- 不确认具体污染源。
- 不写站点质控结论，除非任务明确提供站点数据和质控证据。
- 不自行计算 AQI，除非任务明确要求并提供完整计算口径。
- 不替代气象专家判断输送和扩散条件。
- 不替代主 Agent 生成最终结论。

## 常见输出要点

- 告警摘要
- 监测事实和趋势
- 周边城市同步性
- AQI 或目标污染物口径说明
- 已阅读资产
- 建议插入图片
- 未来风险提示
- 可执行驻场建议
- 不确定性和补证建议
