# 常规监测分析专家 Skill

## 概述
用于空气质量分析中的常规监测事实梳理、AQI 口径判断、污染物变化分析、区域同步性分析和风险提示。该 skill 专注于业务知识和分析逻辑，不绑定具体城市、文件名、报告模板或子 Agent 返回格式。

## 业务知识

- 常规监测分析首先回答“何时、何地、什么污染物、达到什么程度、变化趋势如何”。
- AQI 是综合空气质量指数，不等同于任一单项污染物浓度。
- 首要污染物、分项污染物小时变化和周边城市同步性，是判断污染过程性质的基础证据。
- PM2.5、PM10、NO2、CO 同步上升常提示燃烧、扬尘或累积线索；O3 与 NO2、温度、辐射和区域输送关系需要结合气象判断。
- 周边城市同步抬升可提示区域过程，不同步则更支持本地累积或局地扰动，但都需要结合气象和本地排放信息。

## 分析逻辑

1. 明确告警污染物、AQI、污染等级、首要污染物和触发规则。
2. 梳理目标城市污染物小时变化、峰值、持续时间和告警前后趋势。
3. 对比周边城市同一时段变化，判断是否存在区域同步抬升。
4. 对 AQI 告警，优先识别首要污染物和主要贡献污染物；缺少首要污染物时只写需结合分项污染物确认。
5. 结合未来空气质量预报判断 24-48 小时风险和是否需要加密盯守。
6. 形成可执行建议时，应包含时间窗、核查范围、现场动作、补充数据和升级条件。

## 运城告警溯源场景资产要求

当任务输入为运城市告警溯源分析，且证据目录中存在下列文件时，常规监测分析专家必须先读取并分析这些资产，再生成草稿。缺失资产不得跳过，应在草稿的“不确定性和补证建议”中说明影响。

以目标城市小时数据作为主时间轴，按实际时间顺序划分污染过程。每个阶段必须写明时间点或时间范围，并包含“污染变化、周边情况和业务关注点”。周边城市、火点和预报只能按各自实际有效时次挂接，并写明建议挂接的时间节点；时间不一致时直接说明，不强行对齐。运城场景使用“需要补充确认的信息”说明缺失资产及其业务影响。

| 资产 | 必读/必看内容 | 草稿要求 |
| --- | --- | --- |
| 告警 JSON，例如 `*_alert.json` 或 `latest_alert.json` | 告警时间、触发规则、目标城市、目标污染物、AQI、首要污染物和证据窗口 | 开篇给出告警摘要和触发口径 |
| `target_city_pollutants.json` | 告警前后目标城市 AQI、PM2.5、PM10、O3、NO2、SO2、CO 小时序列 | 梳理峰值、持续时间、变化速率和主要贡献污染物 |
| `nearby_city_pollutants.json` | 周边城市同一时段污染物小时序列 | 判断区域同步性、上风向/周边城市是否共同抬升 |
| `city_pollutant_choropleth.png` | 告警目标污染物在运城市与周边城市的空间分布、图中有效时次和区域差异 | 图片存在时，必须在周边联动分析中插入 `![城市污染物空间分布](city_pollutant_choropleth.png)`，写明实际有效时次、目标污染物、主要空间差异及现场盯守意义，不得仅列入附件清单 |
| `air_quality_24h_forecast.json` | 未来 24 小时 AQI、目标污染物和超标/接近超标时段 | 给出未来风险时段和是否需要加密盯守 |
| `fire_hotspots_summary.json` | 火点数量、时段、距离、方位和强度摘要 | 若火点数量大于 0，说明其只能作为燃烧活动线索，不能直接确认污染源 |
| `fire_hotspots.json` | 火点明细、坐标、时间、亮温和质量标识等字段 | 与风向、轨迹和污染物变化交叉分析；不足时写明需要补充确认的信息 |
| `fire_hotspots_map.png` | 火点空间分布和目标城市相对位置 | 若火点数量大于 0，草稿中必须插入图片引用：`![火点分布](fire_hotspots_map.png)` |

草稿必须包含“已阅读资产”小节，列出实际读取的 JSON 和查看的图片；必须包含“建议插入图片”小节，列出图片文件名、实际有效时次、建议挂接的时间节点和业务化图注。`city_pollutant_choropleth.png` 存在时必须实际插入周边联动正文，不得只作为“建议插入图片”或附件列名；缺失时应在“需要补充确认的信息”中说明其对区域联动判断的影响。若没有可用图片，也要写明“未发现常规监测侧必须插入的图片资产”。

## 边界

- 不确认具体污染源。
- 不写站点质控结论，除非任务明确提供站点数据和质控证据。
- 不自行计算 AQI，除非任务明确要求并提供完整计算口径。
- 不替代气象专家判断输送和扩散条件。
- 不替代主 Agent 生成最终结论。

## 常见输出要点

- 告警摘要
- 监测事实和趋势
- 周边城市同步性
- AQI 或目标污染物口径说明
- 已阅读资产
- 建议插入图片
- 未来风险提示
- 可执行驻场建议
- 不确定性和补证建议
