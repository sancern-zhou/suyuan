# 设计规范（design-rules）

所有数值与 validate_pptx 的检查阈值联动：按本规范设计 → QA 自然通过。

## 1. 画布与栅格

- 画布 16:9（13.333 × 7.5 英寸）。所有坐标用 Inches() 显式声明，禁止依赖默认。
- 页边距：左右 0.6in、上下 0.45in（渲染检查要求内容距边缘 ≥1.5%，本规范留 4% 以上余量）。
- 12 列栅格：列宽 = (13.333 − 1.2 − 11×0.15) / 12 ≈ 0.740in；常用跨列：卡片 3 列、双栏各 5 列、图表+洞察 7+5。
- 元素间距统一 0.15in（栅格 gutter），卡片内边距 0.12in。
- 对齐优先级：先贴栅格线，再微调；同一页内相同类型元素必须等宽等高、左缘对齐。

## 2. 字号阶梯（与 QA 阈值联动）

| 层级 | 字号 | 用途 |
|---|---|---|
| 封面主题 | 40pt | 封面标题 |
| 页面标题 | 28–32pt | 内容页标题（QA 红线：≥24pt） |
| 章节隔页 | 36pt | 章节编号+名称 |
| 关键指标数字 | 28–32pt | 指标卡数值 |
| 正文 | 14–16pt | 要点、说明（上限 18pt） |
| 次级/卡片标签 | 12–13pt | 卡片标题、轴标签、表头 |
| 脚注/来源 | 10–11pt | 数据来源、页脚（QA 红线：≥10pt，检测下限 8pt） |

- 层级差 ≥8pt（QA 检测 max−min<8 判 low_typographic_contrast）。
- 每页字号种类 ≤3 档；标题加粗，正文常规，禁用斜体中文。
- 行距 1.15–1.3；段间距 0.08–0.12in（Pt(6)–Pt(9) space_after）。
- 中文字体统一 **Noto Sans CJK SC**（服务器 fonts-noto-cjk 渲染一致；latin 用 Arial）。
  validate_pptx 传 `expected_fonts: ["Noto Sans CJK SC"]` 校验。设置方法见 code-recipes §2。

## 3. 配色系统（环保政务主题，与既有 deck 对齐）

| 令牌 | 色值 | 用途 |
|---|---|---|
| 主色 primary | #0F766E（teal-700） | 标题强调、图表主线、封面色块 |
| 主色深 primary-dark | #134E4A | 封面/章节隔页底色 |
| 强调 accent | #D97706（amber-600） | 关键警示、对比高亮（每页 ≤1 处） |
| 文本主 text-strong | #1E293B（slate-800） | 标题正文 |
| 文本次 text-muted | #64748B（slate-500） | 次级说明、轴标签 |
| 背景 bg | #FFFFFF | 页面底色 |
| 卡片底 card-bg | #F8FAFC（slate-50） | 卡片、表格隔行 |
| 分隔线 border | #E2E8F0（slate-200） | 细线、卡片描边 |

- 空气质量语义色（全 deck 一致）：优 #22C55E、良 #EAB308、轻度污染 #F97316、中度 #EF4444、重度 #A855F7、严重 #7F1D1D。
- 60-30-10：中性底 60%、主色系 30%、强调色 ≤10%。
- 正文对比度：text-strong/bg ≥ 7:1，text-muted 仅用于 ≥12pt 文字；禁止浅色文字配浅底。
- 图表系列色沿用 create_business_chart 的统一报告主题 SERIES_COLORS，保持与平台其他产出同风。

## 4. 密度与留白（QA 红线）

- 每页正文 ≤**620 字** 且 ≤**20 行**（QA 阈值：>620 字或 >20 行+320 字开始扣分，>900 字判 high_text_density）。
- 一页一个主信息：标题即结论（陈述句），正文只放支撑要点，每点 ≤2 行。
- 指标卡一页 ≤6 张；表格一页 ≤8 行 ×6 列，超出拆页或转图表。
- 留白 ≥20%（QA 渲染检查 ink_ratio>0.48 判密集、>0.58 判过密）。
- 连续两页不得使用完全相同的元素布局签名（QA 判 repeated_layout_pattern）：从版式库交替选用。

## 5. 版式库（坐标以英寸计，x/y/w/h）

| 版式 | 布局要点 |
|---|---|
| 封面 | 深色底（primary-dark）；主题 40pt 居左 1.0/2.6/10/0.9；副题 16pt text-muted；日期+单位 12pt 底部 |
| 目录 | 左侧 3 列宽色带，右侧条目 16pt，编号用主色 |
| 章节隔页 | 大号章节编号（主色 72pt）+ 章节名 36pt；留白充足，无其他元素 |
| 指标条 | 顶部标题；下方 4–6 张等宽指标卡（数值 28–32pt 主色/语义色 + 标签 12pt） |
| 图表+洞察双栏 | 左 7 列图表、右 5 列洞察卡（结论加粗 + 2–3 条要点） |
| 卡片网格 | 2×2 或 2×3 等尺寸卡片，卡片标题 13pt + 正文 12pt |
| 时间线 | 横向轨道线（border 色）+ 节点圆点（主色）+ 事件卡交替上下 |
| 表格页 | 标题 + 表格（表头主色底白字 12pt，隔行 card-bg）+ 底部来源脚注 |
| 结尾 | 深色底，致谢/联系 20pt 居中 |

- 每份 deck 版式序列建议：封面 → 目录 → 章节隔页 × N（每章：指标条/图表页/表格页交替）→ 结尾。
- 相邻内容页强制换版式（如图表+洞察 → 卡片网格 → 表格页循环）。

## 6. 图表规范

按数据形状选型：

| 数据形状 | 图表 | 禁止 |
|---|---|---|
| 时间趋势 | 折线/折线+标记 | 用柱状画长时间序列 |
| 类别对比（≤8 项） | 横向条形 | 用饼图做对比 |
| 构成占比（≤5 项） | 堆叠条形/环形 | 用双饼图 |
| 分布对比 | 箱线/小提琴 | 用折线画分布 |
| 相关性 | 散点 | — |
| 多指标同基准 | 分组条形 | 用雷达图（仅限同量纲综合评分） |

- 已支持的专用业务图型（风玫瑰、日历图、ophage 等）→ 必须 create_business_chart 生成图片后嵌入，禁止重绘。
- 通用图表优先 python-pptx 原生图表（可编辑）；matplotlib 仅用于原生不支持的形式，须套报告主题。
- 轴：最多 1 条辅助轴；y 轴单位写进轴标题；刻度线淡色；删冗余网格线（保留横向淡网格或全删）。
- 图例 ≤4 项直接标注在数据末端/条形上；>4 项才放图例且置顶横排。
- 数据标签：只标关键点（峰值/达标线/最大项），不全标。
- 单页图表 ≤2 张；图表标题写结论（"PM2.5 同比下降 8.6%"），不写中性描述（"PM2.5 变化"）。

## 7. 视觉母题与明暗结构（审美层）

- **三明治结构**：封面与结尾用深底（primary-dark），内容页浅底——或全 deck 统一深底走高级感；禁止随机混用。
- **一个签名母题（motif）贯穿全 deck**：超大数字、统一的卡片处理、圆角图片框——选一个，每页重复。
  ⚠️ 色条/侧边条纹**不能当母题**（AI 生成味的标志，见 §8 黑名单）。
- **每页一个视觉焦点**：超大数字 / 一张图表 / 一张图 / 一句加粗结论——占据视觉主导，其余全部从属。
  没有焦点的"均质排版"是观感平庸的第一来源。
- **大数字 callout**：关键指标 60–72pt + 下方小标签，比表格里的一行数字有力得多；"$87B TAM" 式短促表达
  胜过完整句子。
- **内容优先于样式**：每页必须承载一个具体结论（真实数字/名称/机制/so-what），不是主题词；
  深度来自挑最尖锐的那个事实，不来自堆文字。

## 8. "AI 味"黑名单（观感鉴别，逐条硬规则）

- 🚫 禁标题装饰下划线；禁装饰色条/侧边条纹/卡片单侧描边条/通页眉脚色带——卡片区分用浅底色或阴影。
- 🚫 卡片网格（2×2、3×2、4 联）≤1/5 内容页且不连续出现，仅用于真正同级的并列项（团队/特性矩阵）；
  其余场景用焦点式/分栏/时间线/示意图版式。
- 🚫 正文禁居中——段落与列表一律左对齐，只有标题可居中。
- ❌ 标题字号对比要拉开（内容页标题 ≥28pt 才压得住正文）；禁止全部元素等权重。
- ❌ 间距锁定单一单位：本规范栅格 gutter 0.15in 全 deck 一致，禁止随机 0.2/0.35/0.5 混用。
- ❌ 禁只精修一页其余裸排——要么全 deck 认真，要么全 deck 简洁。
- ❌ 禁文字型装饰线（───、━━━）——分隔用形状或段落边框。
- ❌ 禁正文纯文字页（封面/目录/章节隔页除外）；禁内容溢出形状还留着。
- ❌ 空白页/米色暖底默认（F5F5DC 类）：底色用白或品牌色。

## 9. 图文叠加与图片纪律

- 🚫 **禁止文字直接压满版图片**——必须压字时：图片置底 + 60–80% 不透明深色遮罩矩形 + 文字在最上。
- **优先做法**：图片放限定区域（如右半），文字留在纯色区——比满版+遮罩更稳。
- 🚫 **禁止拉伸变形填框**：宽高比不匹配时裁剪（等比 cover），绝不硬设 w/h 破坏比例——封面图拉伸是
  最显眼的缺陷。
- 灰度自检：把页面想成黑白打印，每个字仍可读吗？
- 装饰性图片小尺寸放角落，不与文字碰撞。

## 10. 引用与数据诚实（政务报告红线）

- **每张图表、每个关键数字带来源行**：页底 10–11pt text-muted，如"数据来源：河南省城市空气质量实时发布系统，2026-10"。
- 🚫 禁把推测值当有来源数字呈现；估算/示意值必须标注"估算"或"示意"。
- 图表轴/类别/单位全部显式标注；删图表垃圾（3D、渐变、冗余网格线与图例）。

## 11. CJK 排版细节与预览漂移

- 中文无空格可断行——长串会在词中间折行：**行要短，中文文本框宽度比英文等效多留 ~15%**。
- 全角字形宽度一致：中文的溢出检测比英文可信，QA 的几何判定可放心依赖。
- **预览漂移警示**：服务器渲染（Noto Sans CJK SC）与收件人打开环境（Windows Office/WPS 回退微软雅黑）
  字宽不同——"预览刚好塞下"在对方机器可能溢出。文本框留 ~10% 宽度余量，不要贴边设计。
- 层级靠字号与字重（Regular/Bold），不靠换第三种字体；全 deck 字体家族 ≤2。
