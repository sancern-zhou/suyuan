# 设计规范（design-rules）

数值与 validate_office 的检查阈值联动：按本规范设计 → QA 自然通过。

## 1. 页面设置

- A4 纵向（21.0 × 29.7cm）；页边距：上下 2.54cm、左右 3.18cm。
- 正文区宽度约 14.6cm ≈ 5.75in；**图片统一宽 5.8in**（平台占位符替换同宽，超出会溢出页宽）。
- 页脚居中页码（PAGE 字段）；超过 3 页的文档建议首页后插目录字段。

## 2. 字体与段落（与 QA 字体检测联动）

| 层级 | 样式 | 字号 | 加粗 |
|---|---|---|---|
| 文档标题（封面型） | Title / Heading 1 | 22pt（二号≈22pt） | 是 |
| 一级标题 H1 | Heading 1 | 16pt | 是 |
| 二级标题 H2 | Heading 2 | 14pt | 是 |
| 三级标题 H3 | Heading 3 | 12pt | 是 |
| 正文 | Normal | 10.5–12pt（五号~小四） | 否 |
| 表注/图注 | Normal+居中 | 10.5pt | 否 |

- 中文字体统一 **Noto Sans CJK SC**，西文 Arial（Normal 与 Heading 样式都要设，
  含 eastasia 节点，设置方法见 code-recipes §1）。
- 正文行距 1.5 倍；段前 6pt / 段后 3pt（标题段前 12pt）。
- 首行缩进 2 字符（公文式），或列表化要点不缩进——全文统一一种。

## 3. 标题结构（QA 硬检查）

- 全文 ≥1 个标准 Heading 样式标题（`docx_no_heading` 红线）；层级禁止跳级
  （H1→H3 会判 `docx_heading_level_jump`），逐级递减、同级连续。
- 章节骨架建议：概述 → 主体（每章一个 H1，小节 H2）→ 结论/建议 → 附表。
- 标题写陈述句（"三季度臭氧浓度同比上升 8%"），不写中性词（"分析结果"）。

## 4. 表格

- 表头：加粗 + 浅底色（#F8FAFC）+ 上下粗边框（三线表风格），列宽显式分配。
- 中文表头，单位写进表头（"浓度 (μg/m³)"），单元格不留空——无数据写 "—"。
- 单表 ≤10 行 ×6 列；超限拆表或转附表 sheet。
- 表题在表上方（"表 N xxx"），图题在图下方（"图 N xxx"），均 10.5pt 居中。

## 5. 图片与图表

- 业务图表必须 create_business_chart 生成后 add_picture 嵌入（宽 5.8in），
  禁止用 matplotlib 重绘平台已支持的专用图型。
- matplotlib 通用图须套统一报告主题（REPORT_THEME/SERIES_COLORS）。
- 每页图片 ≤2 张；连续两图之间必须有正文衔接。

## 6. 内容密度

- 一段一个要点，段落 ≤6 行；能用表格的不用长段文字。
- 结论前置：每章首段给出该章结论，再展开论据。
- 数据必须注明来源与时间范围（脚注或表注），禁止无出处的数值。
