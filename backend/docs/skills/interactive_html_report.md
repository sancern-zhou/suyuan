# 交互式 HTML 报告成稿

## 概述

报告模式的展示主体是自包含的交互式 HTML 页面：对话区内嵌卡片直接渲染，右栏与全屏查看复用同一页面。qmd/Word 仅作为归档出口按需渲染，不在页面里为它们安排入口。

页面运行在**沙箱 iframe（opaque origin）**中，由宿主按内容高度自适应取景。本技能约束页面作者（Agent）写出在这种环境下可运行、可回放、可分享的页面。

## 运行环境硬约束

页面与宿主双向隔离：没有同源访问、没有凭证、没有网络。以下约束违反任何一条即页面不可用：

- **数据全部内联**：图表数据、表格数据、配置在生成时直接写进 HTML。页面不得在运行时取数——禁用 `fetch`/XMLHttpRequest/WebSocket，也没有 localStorage、sessionStorage、cookie 可用。
- **禁外链资源**：内网环境且 CSP 默认档拦截一切外联。脚本、样式、字体、图片要么内联，要么使用**报告包内相对路径资产**（与 qmd 图片同一约定，随包交付随包生效）。禁止 CDN、禁止 `https://` 绝对地址引用静态资源。
- **禁导航与弹窗**：`window.open`、`location.href` 跳转、表单提交到外部均被沙箱拦截。`allow-forms` 仅供页面内筛选控件（下拉、单选）做**纯前端联动**。
- 禁止 `<script src>` 指向任何运行时才能确定的地址；页面是最终产物，不是模板。

## 高度与布局（宿主托管，页面让位）

宿主在响应中注入高度上报运行时：ResizeObserver 监听内容、postMessage 报告宿主、宿主钳制后设定卡片高度（预览态 240~560px，展开态满屏）。页面侧规则：

- **不要自己实现高度上报**（postMessage/resize 监听都不需要）；自带上报不携带宿主协议标识，会被忽略。
- 禁用 `vh`/`vw`/视口单位布局和 `position: fixed`——iframe 高度由宿主按内容设定，视口相关尺寸会形成回环。
- 不要内部固定高度滚动容器（`height: Npx; overflow: auto` 的主内容区）——让文档流自然增高，滚动条交给宿主；长表格直接完整渲染。
- 宽度自适应 320px 起（对话区窄卡与全屏双宿主）；不设固定外宽。
- 根容器给唯一 `id` 并用它初始化图表。

## 兼容性

- 语法上限 **ES2017**：目标环境含麒麟内网 Firefox ESR 78。不用可选链、空值合并之外的.experimental API；模板字符串、箭头函数、`const/let` 可用。
- 图表库用 ECharts 5（UMD 构建），随包资产相对路径引入；option 里数据写死，不请求外部补数。
- 中文文本用系统字体栈，不引外部字体。

## 交付与迭代

1. 组装完整页面后**只调用一次 `create_html_artifact`**，`title` 使用报告业务名（如 `xuchang_air_quality_daily_review`）；内容写进工具参数，不经手临时路径。
2. 用户反馈迭代时 `read_file` 读取当前内容 → `edit_file` 修改 → 重新交付；每轮重新调用一次 `create_html_artifact` 形成新版本，不追加第二个 artifact。
3. 页面内不放下载按钮、不放"导出 Word"入口、不放跳转链接——下载与导出走对话区的文件成果卡片和右栏操作。
4. 交付说明一句话讲清"页面已嵌入对话区，可展开全屏"，不罗列技术细节。

## 内容结构

成稿原则沿用分析报告通用工作流：先结论后论证（金字塔）、关键数字可回溯、来源与口径在页脚注明。展示形态上图表优先、短句为辅：

- 首屏（钳制高度内可见部分）必须给出核心结论与关键指标，不要放大标题留白。
- 筛选控件（时段、站点、因子）用纯前端联动重绘已有数据，联动逻辑简单直接，不做跨数据源查询式交互。
- 数据表随筛选状态切换，不折叠隐藏。

## 明确不做（v1）

- 无宿主桥接：页面不能向对话回传内容、不能发起追问、不能保存用户交互状态。后续开放 postMessage 桥后本节更新。
- 不做多页站点：一个 artifact 一个页面；多章节用锚点内滚动或分区布局表达。
- 不做打印样式适配：归档出口是 qmd/Word，页面不承担打印版式。
