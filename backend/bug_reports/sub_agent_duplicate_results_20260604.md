# Bug Report: 子Agent重复返回结果

## 发生时间
2026-06-04 21:52:49

## 问题描述
调用 `call_sub_agent` 时，返回了大量重复的工具结果，导致发送了多条重复消息给用户。

## 复现步骤
1. 用户请求：查询广州未来一周空气质量数据
2. 调用 `call_sub_agent`，参数：
   - `target_mode`: "query"
   - `goal`: "查询广州市未来一周的空气质量数据，包括AQI、PM2.5、PM10、主要污染物等指标"
3. 子Agent返回正确结果
4. 但主Agent接收到大量重复的工具结果（重复次数约30+次）

## 现象
- 同一个 `call_sub_agent` 调用返回了多次相同的结果
- 每次结果都包含相同的 session_id 和查询结果
- 导致用户收到大量重复消息

## 影响范围
- 用户体验：收到大量重复消息
- 系统资源：可能造成不必要的资源消耗

## 临时解决方案
手动停止发送，向用户解释情况

## 建议排查方向
1. 检查 `call_sub_agent` 的返回处理逻辑
2. 检查是否有循环调用或重复触发的机制
3. 检查消息队列或事件处理是否有重复消费的情况
4. 检查子Agent会话管理是否有问题
