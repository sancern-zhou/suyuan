# Draw.io Comparison Matrix Pattern

适用于方案对比、指标对比、城市对比、工具/策略对比、优劣势分析和选型评估。

## 布局

1. 行列标题必须清晰，行表示对象，列表示维度。
2. 对象超过 8 个或维度超过 6 个时，拆分矩阵或改为表格型产物。
3. 重要结论可以放在矩阵右侧或底部摘要区。

## Shape 语义

1. 表头使用深色或浅灰底。
2. 单元格使用矩形，保持统一宽高。
3. 评级可用小圆点、短标签或低饱和色块表达。
4. 注释框用于解释评分口径。

## 颜色

1. 颜色只表达等级或状态，不用多色装饰。
2. 常用语义：绿色=优/通过，橙色=中/需关注，红色=差/风险，灰色=不适用。
3. 同一列的颜色语义必须一致。

## 质量门槛

1. 单元格文字短，避免长句。
2. 如果需要大量文字解释，改为报告段落或表格，而不是 draw.io 矩阵。
3. 矩阵必须有明确对比口径。
