# Draw.io Swimlane Pattern

适用于多个部门、角色或系统之间存在责任边界与交接的业务流程。

## 布局

1. 泳道只表达责任主体，不同时表达阶段；阶段用分区或标题表达。
2. 建议 2 至 5 条泳道，主流程方向保持一致。
3. 节点必须完整落在所属泳道内容区内，禁止压住泳道标题。
4. 跨泳道连线表示交接，同泳道内连线表示主体内部动作。

## Shape 语义

1. 泳道标题：部门、角色、系统或责任主体。
2. 圆角矩形：人工动作或业务步骤。
3. 矩形：系统动作或自动任务。
4. 菱形：确有互斥分支的判断。

## 连接与文本

1. 每次跨泳道交接应标注明确对象或动作。
2. 异常、退回和补正路径放在主流程下方或右侧。
3. 判断出口必须标注条件，汇合点应清楚可辨。

## 质量门槛

1. 泳道之间的空白、宽度和节点尺寸保持稳定。
2. 跨泳道连线不得沿泳道边界长距离重叠。
3. 如果同一主体占据绝大多数步骤，改用普通流程图而不是泳道图。
