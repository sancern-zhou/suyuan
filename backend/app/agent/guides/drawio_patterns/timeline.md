# Draw.io Timeline Pattern

适用于路线图、时间线、里程碑、计划排期、事件复盘和阶段演进。

## 布局

1. 使用水平时间轴，节点按时间顺序排列。
2. 阶段用容器、色带或分区表达。
3. 里程碑使用菱形、小圆点或短竖线，不使用大块复杂节点。
4. 多条并行计划使用泳道。

## 文本

1. 每个节点只写时间、动作和交付物。
2. 长说明放入注释节点，不塞进里程碑节点。
3. 时间粒度保持一致，例如不要混用“2026Q1”和“3月12日”。

## 连接

1. 普通时间顺序可不画箭头，使用轴线表达。
2. 依赖关系少量使用虚线箭头。
3. 依赖过多时改为甘特图或任务矩阵。

## 质量门槛

1. 里程碑超过 12 个时，按阶段拆分。
2. 每个阶段应有明确标题和起止范围。
3. 不在时间线中同时表达复杂系统结构。
