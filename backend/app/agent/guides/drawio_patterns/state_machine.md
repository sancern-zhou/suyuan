# Draw.io State Machine Pattern

适用于对象、告警、工单或任务在明确状态之间发生的转换。

## 布局

1. 初始状态放在左侧或顶部，主状态沿单一方向排列。
2. 正常路径位于主轴，失败、取消和回退状态放在外侧。
3. 状态超过 8 个时按阶段分组或拆分子状态机。

## Shape 语义

1. 小实心圆：初始状态。
2. 圆角状态节点：稳定状态，使用名词或完成时描述。
3. 双圆或明确终止节点：终止状态。
4. 判断不是状态；条件写在转换线上。

## 连接与文本

1. 每条转换标注 `事件 [条件] / 动作` 中实际存在的部分。
2. 同一状态的多个出口必须能通过事件或条件区分。
3. 自循环使用短回环，不得绕过其他状态。
4. 不得把业务处理步骤伪装成状态；连续动作应改用流程图。

## 质量门槛

1. 除明确终止状态外，不应出现无出口状态。
2. 不允许无法解释的重复状态名称。
3. 闭环、回退和重试必须在视觉上可独立追踪。
