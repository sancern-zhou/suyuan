# Draw.io Decision Tree Pattern

适用于判断逻辑、规则引擎、告警分级、分诊流程、策略选择和条件推理。

## 布局

1. 根节点放顶部或左侧，分支方向保持一致。
2. 深度超过 4 层时，拆分子树或折叠为“规则组”节点。
3. 同一父节点下的分支数量超过 5 个时，优先改为表格或矩阵。

## Shape 语义

1. 菱形：判断节点。
2. 矩形：处理动作、规则组、下一步任务。
3. 圆角矩形：最终结果、分级结论、建议动作。
4. 注释框：规则口径、阈值来源、例外说明。

## 连接

1. 每条分支线必须标注条件，例如 `PM2.5 > 75`、`有有效证据`、`否`。
2. 条件互斥时，应让分支从同一判断节点发出。
3. 默认路径和异常路径要明显区分。

## 质量门槛

1. 不要在一个判断节点内塞入多个复合条件；复杂条件应拆分。
2. 叶子节点必须是明确结论或动作，不写模糊结果。
3. 大型规则树应先画总览，再按规则组拆分局部图。
