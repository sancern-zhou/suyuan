# Draw.io ER and Data Model Pattern

适用于实体、字段、主外键、基数和数据对象关系。

## 布局

1. 核心实体放在中心或主轴，关联实体靠近其主要依赖。
2. 建议单图不超过 8 个实体；更大模型按数据域拆分。
3. 实体之间保留足够通道，避免关系线穿越字段文本。
4. 同一数据域使用容器分区，但容器不参与实体关系。

## Shape 语义

1. 实体使用带标题栏的表格节点。
2. 字段按主键、外键、必填字段和普通字段稳定排序。
3. 主键、外键、唯一约束使用文字或小型标签表达，不只依赖颜色。

## 连接与文本

1. 关系线必须标注基数，如 `1`、`0..1`、`1..N`。
2. 多对多关系应通过关联实体表达，不直接画一条含糊连线。
3. 关系名称使用业务动词，技术字段名可作为子标签。

## 质量门槛

1. 字段字号不得为了塞入更多实体而低于 10px。
2. 关系端点必须连接到正确实体，禁止悬空。
3. 如果目标只是列出字段而没有实体关系，应改用表格而不是 ER 图。
