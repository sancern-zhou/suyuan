# execute_python 静态图表规范

工具 Schema 要求 Agent 在使用 execute_python 调用 matplotlib、seaborn、Plotly 静态导出或其他 Python 绘图库前，通过 read_file 阅读本文件。该要求由 Agent 按任务场景执行，工具运行时代码不检测阅读状态，也不会因此阻断执行。

工具 Schema 已说明所有场景共同遵守的输入文件、沙箱、输出路径和返回状态规则。本文件只补充静态图表的选型、视觉和环境领域约束。

## 工具选择

先匹配专用业务图型。以下图型必须使用 create_business_chart，不能使用 Python 或 ECharts 重画：

- aqi_calendar
- pollutant_calendar
- pollutant_wind_rose
- generic_pollutant_wind_rose
- wind_timeseries
- weather_timeseries

问数模式的通用交互图优先使用 execute_echarts_python；专家和报告模式的通用静态图使用 execute_python。流程图、架构图和步骤图使用画板 Agent。

## 通用视觉规范

- 使用系统注入的 REPORT_THEME、SERIES_COLORS 和 theme_color；不要硬编码 SimHei 或不支持中文的字体。
- 标题约 14 pt，轴标签约 11 pt，刻度和图例约 9.8 pt，数据标签约 10.5 pt，注释约 8.5 pt。
- 白底、标题左对齐、弱化轴线、轻网格、无图例边框，避免装饰背景和无分析意义的 3D。
- 相同变量跨图保持颜色一致；变化量和相关系数使用合适的顺序或发散色图，并提供单位和色标。
- 标题不写“图1”等编号，编号由报告层负责。
- 轴标签必须包含单位；图注说明时间范围、样本口径、缺失处理和数据来源。
- 相关关系不能直接解释为因果，不得编造贡献率、显著性或置信区间。
- seaborn.set_theme 会覆盖默认主题，调用后应执行 apply_report_style。

## 保存与文件组织

- 使用 save_chart(fig, filename) 保存并让工具自动归档。
- 通用图默认 160 DPI；预计进入报告的 PNG 使用 240 DPI，印刷或细节密集场景可使用 300 DPI。
- 默认一个独立分析问题一个图片文件。趋势、分布、排名和相关性通常分别保存。
- 一次调用可以创建多个 Figure 并分别保存，不要为了减少调用次数强行拼图。
- 只有共享坐标、同步时间轴或联合阅读确有必要，或者用户明确要求时，才使用多子图。
- 保存后检查中文缺字、裁切、标签重叠、图例遮挡和缩放后的可读性。

最小示例：

    import matplotlib.pyplot as plt

    fig, ax = plt.subplots(figsize=(6.0, 3.8))
    ax.plot([1, 2, 3], [1, 4, 9], label="指标")
    ax.set_xlabel("日期")
    ax.set_ylabel("数值（单位）")
    legend_below(ax, ncols=1)
    save_chart(fig, "trend.png", dpi=240)

## 报告插图尺寸

- 未知模板时按 A4 纵向单栏约 5.8 英寸宽度设计。
- 常规趋势、柱状和散点图宽高比约 1.4–1.8，可从 6.0 × 3.8 英寸开始。
- 最终插入报告后，刻度和图例一般不小于 9 pt，轴标签不小于 10 pt，标题不小于 12 pt。
- 报告 PNG 在约 5.8 英寸宽度下宜有约 1400–1800 像素宽。
- DPI 只能改善栅格清晰度，不能补救物理尺寸过小；过密时调整画布、标签密度或拆图。
- 图例通常放在图下方，长图例分行排列，不能横向撑宽画布。

## 环境领域配色与图例

- AQI/IAQI 等级色使用：优 #00E400、良 #FFFF00、轻度 #FF7E00、中度 #FF0000、重度 #99004C、严重 #7E0023。
- 缺测使用灰色 MISSING_COLOR，不能表示为“优”。
- 污染物浓度等级必须按污染物、平均时间、日期和单位调用 pollutant_color 或 get_pollutant_scale 映射；不能把浓度直接套入 AQI 数值区间。
- 等级颜色用于等级色带、超限点或状态提示；相关系数、贡献率和变化量不使用 AQI 等级色。
- 每张图必须有足以解释系列、颜色、符号和参考线的图例、色标或直接标注。
- 连续热力图必须有带单位的色标；等级热力图使用固定分级图例，不能根据当前数据最小值和最大值重新拉伸等级色。

## 标准限值与评价口径

- 有适用环境质量限值的浓度趋势或对比图必须标出标准线，并说明标准版本、阶段、等级、平均时间、数值和单位。
- 先确认功能区适用等级，不能无依据默认二级。
- 使用 get_environment_limit 获取限值；使用 add_standard_limit 绘制，并保证数据平均时间和单位匹配。
- 小时数据与日均限值仅作参考时必须显式使用 reference_only=True，不能用于该小时数据的达标判定。
- 管理目标、预警阈值和国家标准使用不同名称和线型，不能把内部目标标成国标限值。
- 当前环境空气标准使用 GB 3095—2026 和 HJ 633—2026；数据日期不得早于 2026-03-01。
- 2026—2030 年使用过渡限值，2031 年起使用正式限值；跨阶段时间序列必须分段绘制。
- CO 内置单位为 mg/m3，其他基本污染物为 ug/m3；单位不一致时先换算。
- None/NaN 表示缺失；负值和无穷值不能参与等级映射。
- 内置标准不适用于水、土壤、噪声、排放标准或地方标准，这些场景必须核实对应标准。

## 风向与矢量

- 气象风向是来向：正北 0°，顺时针增加。输送箭头表示去向，必须在图例或图注说明。
- 来向角转换为气流分量：u = -speed × sin(theta)，v = -speed × cos(theta)。
- 仅表示方向时使用等长真实角度箭头；同时表示风速时使用真实 u/v 分量和统一缩放规则。
- 时间轴和浓度轴单位不一致时使用 quiver 的 angles='uv' 保持屏幕真实方向。
- 静风不能凭角度画确定方向；零风速、缺失方向和静风应分别表达。
- 不把风向角作为普通线性数值求算术平均。
- 地图矢量必须考虑投影和局地北向，不能直接把 m/s 当作经纬度增量。

## 数据表达检查

- 缺失值不填零，时间缺测保留断线；插值必须说明。
- 预测与实测使用不同线型或符号，预测不确定性使用区间表示。
- 可比图保持分级断点、系列颜色和坐标范围一致。
- 柱状图通常从零开始；截断坐标必须说明。
- 超限点可以突出，但图例必须解释判据。
- 交付前检查标准线、图例、色标、中文、单位和图注是否完整。
