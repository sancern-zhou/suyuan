# PPT Master Layout Rules

## Structure Rules

- The cover appears once only.
- Outline items named like cover/title page, including `封面`, `标题页`,
  `cover`, or `title`, are merged into the automatic cover and must not create
  body slides.
- Agenda or contents pages, including `目录`, `大纲`, `议程`, `agenda`,
  `contents`, or `table of contents`, must use the agenda layout.
- Agenda pages must not be replaced with matrix, card, or chart layouts.
- Each slide should communicate one core message.

## Layout Diversity

- Do not use the same layout on many adjacent pages.
- Continuous chart sections must not cycle between only two layouts.
- A continuous chart-heavy section should use a broader chart layout pool,
  including at least four chart layout forms when the section is long enough.
- Do not make every data page a fixed left-chart/right-text composition.

## Content Density

- Avoid pure text pages in formal decks.
- Add chart, metric card, process, matrix, domain diagram, or action component
  when a page would otherwise be text-only.
- Split dense pages instead of shrinking text until it becomes unreadable.
