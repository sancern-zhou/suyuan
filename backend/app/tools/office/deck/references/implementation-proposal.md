# Implementation Proposal Deck

适用于实施方案、建设方案、二期项目方案。

## 推荐叙事

1. `cover`
2. `executive_summary`
3. `section_divider` 背景与问题
4. `three_column_points` 建设目标
5. `architecture_overview` 总体架构
6. `implementation_plan` 建设内容和阶段
7. `roadmap` 时间路线
8. `responsibility_matrix` 分工机制
9. `budget_breakdown` 投资或资源安排
10. `risk_matrix` 风险与保障
11. `closing_actions` 决策请求或下一步行动
