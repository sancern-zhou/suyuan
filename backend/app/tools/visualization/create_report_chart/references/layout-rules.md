# Layout Rules

Avoid packing many analyses into one figure.

- One main chart per image is the default.
- Split complex multi-view requests into multiple images.
- More than one subplot is only acceptable when each subplot has low text density.
- Warn when text overlaps, text falls outside the canvas, or the chart contains too many labels.
- If a chart needs a paragraph of explanation inside the image, move that explanation to the report text.
