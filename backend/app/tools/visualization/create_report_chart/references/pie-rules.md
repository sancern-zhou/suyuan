# Pie Rules

Pie charts are only suitable for a small number of clear categories.

- Put small-slice labels outside the pie with leader lines.
- Merge tiny categories into `Other` when there are too many slices.
- Use TopN plus Other when a pie would have excessive labels.
- Prefer horizontal bars when there are many categories, long labels, or several small shares.
- Do not force percentages into small slices.
