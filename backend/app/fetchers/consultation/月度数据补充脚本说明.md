# 月度空气质量数据补充脚本

## 概述

生成三个独立的月度空气质量数据补充脚本，用于支撑月报PPT生成：

1. **区县排名数据** (`district_ranking_{yyyymm}.csv`)
2. **高值站点数据** (`station_high_value_{yyyymm}.csv`)
3. **污染过程及组分数据** (`pollution_events_{yyyymm}.json` + 组分CSV)

## 脚本说明

### 1. 区县排名数据

**文件**: `district_ranking_{yyyymm}.csv`

**内容**:
- 各区县所有污染物浓度和排名
- 同比数据（与去年同期对比）

**字段**:
- district: 区县名称
- city: 所属城市
- pm25, pm10, no2, o3, aqi, co, so2: 污染物浓度
- {pollutant}_yoy: 同比变化百分比

**数据来源**: `execute_query_gd_suncere_district_report`

**定义**:
- 所有污染物：PM2.5、PM10、NO2、O3、AQI、CO、SO2
- 同比计算：(当期值 - 去年同期值) / 去年同期值 × 100%

### 2. 高值站点数据

**文件**: `station_high_value_{yyyymm}.csv`

**内容**:
- 高值站点列表（浓度排名前十 OR 同比变差幅度排名前十）

**字段**:
- station: 站点名称
- city: 所属城市
- high_value_reason: 高值类型（如"pm25浓度"或"pm10同比"）
- pm25, pm10, no2, o3, aqi, co, so2: 污染物浓度
- {pollutant}_yoy: 同比变化百分比

**数据来源**: `execute_query_station_standard_report`

**高值定义**:
- 污染物浓度排名前十
- OR 同比变差幅度排名前十（正值表示变差）

### 3. 污染过程及组分数据

**文件**:
- `pollution_events_{yyyymm}.json`: 污染过程描述
- `hourly_pollution_*.csv`: 常规污染物小时数据
- `vocs_components_*.csv`: VOCs组分数据
- `pm25_components_*.csv`: PM2.5组分数据
- `component_data_manifest_{yyyymm}.json`: 组分数据清单

**污染过程定义**:
- 至少一天AQI>100

**数据来源**:
- 污染过程识别: `execute_query_gd_suncere_city_day`
- 常规污染物小时: `execute_query_gd_suncere_station_hour`
- VOCs组分: `GetVOCsDataTool`
- PM2.5组分: `GetParticulateComponentsTool`

**采样策略**:
- 根据污染过程选择涉及的城市/站点
- 如果没有污染过程，则不生成组分数据

## 使用方法

### 方法1: 直接调用类

```python
from app.fetchers.consultation.monthly_air_quality_supplements import MonthlyAirQualitySupplements

# 创建生成器
generator = MonthlyAirQualitySupplements(2026, 5)

# 生成所有补充数据
results = generator.generate_all()

# 或者单独生成
district_file = generator.generate_district_ranking()
station_file = generator.generate_station_high_value()
pollution_events, events_file = generator.identify_pollution_events()
if pollution_events:
    component_files = generator.generate_component_data(pollution_events)
```

## 错误处理

脚本包含完善的错误处理：

1. **数据查询失败**: 捕获异常，打印错误信息，继续执行其他任务
2. **无数据情况**: 返回 `None`，不生成文件
3. **污染过程不存在**: 不生成组分数据，返回空列表

## 性能优化

1. **异步调用**: VOCs和PM2.5组分数据查询使用异步方法
2. **条件执行**: 仅在有污染过程时才生成组分数据
3. **数据限制**: 设置合理的数据查询上限，避免超时

## 扩展性

脚本设计易于扩展：

2. **新增字段**: 在CSV写入方法中添加字段名

## 常见问题

**Q: 为什么没有生成组分数据？**
A: 因为本月没有污染过程（AQI>100的天数），这是正常的。

**Q: 生成的CSV文件编码是什么？**
A: UTF-8 with BOM（`utf-8-sig`），确保Excel正确显示中文。

**Q: 如何修改高值定义？**
A: 在 `_identify_high_value_stations` 方法中修改TOP数量或阈值。

**Q: 如何添加新的污染物？**
A: 在 `__init__` 方法中的 `pollutants` 列表中添加新的污染物名称。
