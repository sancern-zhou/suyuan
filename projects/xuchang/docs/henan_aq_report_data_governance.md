# 河南省城市空气质量大数据平台报表数据 —— 数据与语义治理说明

面向在部署机上做数据治理、语义治理的同事。本文说明这批数据的来源、存储位置、表结构、口径和接入语义层的建议。

## 1. 概述

- **来源**：河南省城市空气质量大数据综合应用系统（省监测中心），「报表报告 → 年度对比」接口。
- **范围**：许昌市、5 个区（魏都区、建安区、开发区、示范区、东城区）、4 个县市（鄢陵县、襄城县、禹州市、长葛市）。
- **内容**：月度、年度、当月累计、当年累计，以及平台直接给出的同比。
- **数据起点**：2020 年（2015–2019 年平台无数据）。
- **用途**：为许昌项目的问数、专家分析提供官方口径的月度及以上统计数据，不做本地计算。

## 2. 存储位置

SQL Server：`180.184.30.94:1433`，库 `XcAiDb`。

**三张表全部是新建的**，不修改、不写入任何已有表：

| 表名 | 内容 | 更新方式 |
|---|---|---|
| `HenanPlatformAqYearStat` | 完整年度（全年） | 历史一次性；每日顺带回补上一年 |
| `HenanPlatformAqMonthStat` | 完整自然月 | 历史一次性；每日顺带回补上一个完整月 |
| `HenanPlatformAqAccumulateStat` | 当月累计、当年累计（截至昨天） | 每天一份快照 |

## 3. 表结构（三张表相同，45 列）

### 标识与维度

| 列 | 类型 | 含义 |
|---|---|---|
| `standard` | NVARCHAR(10) | 评价标准：`new`（新标准）/ `old`（老标准） |
| `data_type` | NVARCHAR(10) | 固定 `SK`（实况；另一口径为 `BK` 标况，本任务未取） |
| `is_deduct` | TINYINT | 固定 `1`（扣沙） |
| `region_level` | NVARCHAR(10) | `city`（市）/ `district`（区）/ `county`（县市） |
| `region_id` | NVARCHAR(20) | 平台内部区域 ID（见第 5 节） |
| `admin_code` | NVARCHAR(20) | 行政区划码，如 `411000` |
| `region_name` | NVARCHAR(50) | 区域名称 |
| `stat_year` | INT | 本期年份 |
| `stat_month` | INT | 本期月份（仅月度、当月累计有值） |
| `period_type` | NVARCHAR(10) | `year` / `month` / `ytd` / `mtd` |
| `period_start` / `period_end` | DATE | 统计区间起止 |

### 指标（14 项，均为 DECIMAL(12,4)，存精确值）

| 列 | 指标 | 单位 |
|---|---|---|
| `pm25` / `pm10` | PM2.5 / PM10 | μg/m³ |
| `so2` / `no2` | SO₂ / NO₂ | μg/m³ |
| `co` | CO-95 | mg/m³ |
| `o3_8h_90` | O₃-8H-90 | μg/m³ |
| `total_index` | 综合指数 | — |
| `good_rate` | 优良率 | % |
| `good_days` | 优良天数 | 天 |
| `bad_days` | 重度及以上污染天数 | 天 |
| `bad_rate` | 重度及以上污染比例 | % |
| `o3_over_days` | 臭氧超标天数 | 天 |
| `lost_fine_days` | 因沙尘损失优良天数 | 天 |
| `dust_days` | 沙尘天数 | 天 |

### 同比（14 项，`yoy_` 前缀）

| 列 | 含义 |
|---|---|
| `yoy_pm25` 等 14 列 | 与上一年同期对比的结果，**由平台直接返回，不是本地计算** |
| `yoy_base_year` | 同比基期年份 |

同比的含义按指标类型不同：

| 指标类型 | 同比含义 |
|---|---|
| 浓度、综合指数 | 变化率（%） |
| 优良率、重度及以上污染比例 | 百分点 |
| 各类天数 | 天数差 |

取整值与精确值各有一套同比；本任务存的是**精确值口径**的同比。

### 留痕

| 列 | 含义 |
|---|---|
| `raw_json` | 该区域在接口原始响应里的完整字段 |
| `fetched_at` | 本次抓取时间 |
| `created_at` | 入库时间 |

### 唯一键（MERGE upsert 的依据）

| 表 | 唯一键 |
|---|---|
| `HenanPlatformAqYearStat` | `standard + data_type + is_deduct + region_id + stat_year` |
| `HenanPlatformAqMonthStat` | `standard + data_type + is_deduct + region_id + stat_year + stat_month` |
| `HenanPlatformAqAccumulateStat` | `standard + data_type + is_deduct + region_id + period_type + period_start + period_end` |

重复抓取同一键只会覆盖更新，不会产生重复行。

## 4. 口径要点（治理时务必注意）

1. **优良率的分母是有效天数，不是日历天数。** 例如建安区某段优良 213 天，按日历算是 64.7%，平台给的是 69.6%。优良率必须直接取接口值，不能用「优良天数 ÷ 日历天数」重算。
2. **「新标准」参数对所有年份都生效。** 平台按传入的标准重算，不会按年份自动切换。同是 2025 年全年，新标准优良率 59.2%，老标准 69.6%。本任务对 2020–2025 年的历史数据新、老标准各存一份；2026 年起只取新标准。
3. **2020 年没有同比**（2019 年无数据）。
4. **年度表只存完整年份。** 当年的「年初至今」在累计表，每天一行快照。
5. **当月累计按「截至昨天」。** 当天的值在当天抓不到。
6. **「日报及时段查询」接口返回的是逐日明细，不是累计。** 本任务的累计全部来自「年度对比」接口的时间段模式。
7. **每个响应固定带「全省除济源」「全省」两行**，数值与许昌市相同，是镜像行，已丢弃，不入库。
8. **「十三五 / 十四五」这组单选不进入请求参数**，不影响取数。
9. **值类型在接口里数字与字符串混杂**，入库前已统一为数值。

## 6. 抓取方式与频率

- **历史全量**：一次性抓取，498 个请求，约 3.5 分钟。
- **每日**：当月累计、当年累计，并回补上一个完整月和上一年完整年，共 15 个请求。
- **调度**：每天 01:00；若抓取中被挤下线，03:00 再试一次，失败后当天不再继续。
- **登录**：账号为多人共用、单会话互踢。每次运行最多登录 1 次；被挤下线后冷却 2 小时内不再登录；账号密码错误累计 2 次后永久停止，需人工解除。

抓取脚本为本地独立脚本，不在本仓库：`D:\溯源\.codex_tmp\henan_aq_job\henan_aq_job.py`（部署机如需运行，需能访问省平台专网 `10.41.109.141` 并配置账号环境变量）。

## 7. 语义治理接入建议

### 7.1 维度建议

| 维度 | 字段 | 说明 |
|---|---|---|
| 区域 | `region_level`、`region_id`、`region_name`、`admin_code` | 市 / 区 / 县市三级 |
| 评价标准 | `standard` | 新 / 老，2025 年及以前两套都有 |
| 时段 | `period_type`、`period_start`、`period_end`、`stat_year`、`stat_month` | 年 / 月 / 当年累计 / 当月累计 |

| 同比 | `yoy_*`、`yoy_base_year` | 平台直接返回 |

### 7.2 与现有资产的关系

- `dat_city_month_report` / `dat_city_year_report`：全国城市月报、年报排名（含 338 / 168 / 省内排名），与本任务不同源、不同范围，不要混用。
- `city_168_statistics_new_standard` / `old_standard`：168 重点城市的统计，与本任务不同源。
- `HenanCityAccumulateRanking`：河南空气质量 APP 的月/年累计排名，该数据源已于 2026-09 停服。
- `projects/xuchang/data-ops/` 下另有官方月报链路（`ProvinceMonthReport`，DataCrawler MySQL），口径对照时留意。

## 8. 数据量与校验

| 表 | 首次入库行数 | 校验 |
|---|---|---|
| `HenanPlatformAqYearStat` | 120（6 年 × 10 区域 × 2 标准） | 键无重复；抽样与平台一致 |
| `HenanPlatformAqMonthStat` | 1540（82 个月 × 区域 × 标准） | 月度加总等于年度 |
| `HenanPlatformAqAccumulateStat` | 每日 20 行 | 同日重跑不重复 |

校验结论：抽样数值与平台一致；月度加总等于年度；同一天重复运行不产生重复行。
