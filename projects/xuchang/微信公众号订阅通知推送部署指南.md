# 微信公众号订阅通知推送部署指南

面向目标用户（局长/科长/区县/执法等业务角色）的个人微信点对点推送，与
微信群 RPA 广播互补。首期覆盖**月度特征分析**（每月 2 日）与**企业核查
线索周报**（每周一）两个场景——它们此前仅有 APP 渠道，而用户不习惯打开
App。渠道形态为**订阅通知**（模板短字段摘要提醒），完整通报仍走微信群。

## 一、前置条件（决定可行性，尽早确认）

1. **认证服务号**：主体建议为政府/事业单位。未认证服务号没有订阅通知
   与客服消息接口权限。
2. **类目与模板申请**：公众号后台 → 设置 → 公众号设置 → 服务类目，
   申请「政务民生 - 生态环境」相关类目；然后在 功能 → 订阅通知 中申
   请**长期订阅**模板（用户授权一次即可持续接收）。
   - 若类目只能拿到**一次性订阅**：发送接口一致（代码不用改），但每推
     一条消耗用户一次授权，周报场景需要持续引导用户重新授权，运营成
     本高。建议优先争取长期订阅类目。
3. **公网回调可达**：微信服务器要能访问 `https://<域名>/api/wechat-mp/callback`。
   nginx 需要把该路径反代到后端网关（参照现有 `/api/` 反代规则加一条
   精确 location；本机 80/443 需公网出口，内网部署需先解决外网映射）。

## 二、后端配置

`backend/.env` 追加（web 与 worker 成对使用同一份）：

```bash
# 微信公众号订阅通知渠道
WECHAT_MP_ENABLED=true
WECHAT_MP_APP_ID=wx1234567890abcdef
WECHAT_MP_APP_SECRET=<公众平台-开发-基本配置里的 AppSecret>
WECHAT_MP_TOKEN=<自定义 Token，与公众平台服务器配置一致，仅用于回调验签>
WECHAT_MP_API_PREFIX=/api/wechat-mp
WECHAT_MP_TIMEOUT_SECONDS=15
```

说明：
- `WECHAT_MP_TOKEN` 留空时回调路径在网关层整体关闭（默认安全）。
- 另在微信公众平台把**服务器 IP** 加入 IP 白名单（获取 access_token 用）。

## 三、公众平台服务器配置

公众号后台 → 设置与开发 → 基本配置 → 服务器配置：

| 项 | 值 |
|---|---|
| URL | `https://<域名>/api/wechat-mp/callback` |
| Token | 与 `WECHAT_MP_TOKEN` 一致 |
| 消息加解密方式 | **明文模式**（首期；安全模式需扩展 EncodingAESKey 解密） |
| 数据格式 | XML |

启用前先用 URL 验证（后端 GET 验签回显 echostr 已实现）。

## 四、模板配置

1. 在公众平台申请到订阅通知模板后，拷贝
   `projects/xuchang/wechat_mp_templates.example.json` 到数据登记目录
   （`DATA_REGISTRY_DIR`）下重命名 `wechat_mp_templates.json`，填入
   `template_id` 并按模板字段顺序调整 `field_keys`。
2. 场景 → fields 语义对照：
   - `monthly_review`：报告类型 / 月份 / 通报首行摘要 / 生成日期
   - `enterprise_clue`：报告类型 / 统计窗口 / 周报首行摘要 / 生成日期
3. 模板未配置时对应场景自动跳过公众号渠道并记日志，不影响 APP/微信群。

## 五、用户绑定流程（扫码即绑定，无需装 App）

身份沿用 APP 账号体系（`APP_ACCOUNTS_JSON`），公众号 openid 是账号的
附加绑定；受众仍由 `push_audiences.json` 的角色配置决定。

1. 管理员为账号生成绑定二维码（网关管理员登录态调用）：

   ```bash
   curl -X POST https://<域名>/api/wechat-mp/admin/bind-qrcode \
     -H "Authorization: Bearer <管理员token>" -H "syscode: <syscode>" \
     -H "Content-Type: application/json" \
     -d '{"account": "大气科1"}'
   # 返回 {"account":"大气科1","ticket":"...","url":"https://mp.weixin.qq.com/cgi-bin/showqrcode?ticket=..."}
   ```

   把返回的 `url`（二维码图片链接）直接微信发给目标用户。
2. 用户微信扫码并关注公众号 → 后端回调自动完成 账号↔openid 绑定，并
   best-effort 发欢迎语（关注 48h 窗口内）。
3. 用户在公众号内完成一次**订阅授权**（长期订阅模板一次即可）。授权/
   拒收状态由 `subscribe_msg_popup` 回调自动回写。
4. 管理端查询/删除绑定：

   ```bash
   curl -H "Authorization: Bearer <管理员token>" https://<域名>/api/wechat-mp/admin/bindings
   curl -X DELETE -H "Authorization: Bearer <管理员token>" https://<域名>/api/wechat-mp/admin/bindings/大气科1
   curl -H "Authorization: Bearer <管理员token>" https://<域名>/api/wechat-mp/admin/status
   ```

## 六、推送链路与运维口径

```
fetcher（cron 冻结证据包）
  └─ publish_event → workflow（monthly_review / enterprise_clue）
       ├─ APP：EventTaskDelivery → 广播收件箱 + GeTui（原链路不变）
       └─ 公众号：push_wechat_mp_notice(kind, fields, roles)
            ├─ 受众：roles → push_audiences.json 角色 → APP 账号（复用）
            ├─ 绑定：wechat_mp_bindings.json 查 openid（social 目录）
            │    跳过：未绑定 / 已取关 / 已拒收该模板
            └─ 发送：subscribe/bizsend（stable_token 自动续期）
                 43101（未订阅/拒收）→ 回写拒收状态
                 43104（已取关）→ 回写取关状态
```

- 公众号渠道整体 try/except 隔离，任一失败不影响微信群与 APP。
- 绑定文件：`<social目录>/wechat_mp_bindings.json`（原子写，勿手工编辑
  运行中的文件）。
- 一次性订阅降级运营：推送返回 43101 表示授权额度耗尽/被拒，需引导用户
  重新进入公众号授权；长期订阅模板无此问题。
