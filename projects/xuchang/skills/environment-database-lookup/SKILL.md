# 环境数据可复现查询

## 适用边界

用于环境管理场景中的监测、气象、排放、企业、区域同步和监管数据查询。目标是取得回答当前问题所需的最小事实集，不把一次业务问答扩展成完整数据盘点或研究项目。

## 默认流程

1. 明确对象、时间范围、地区、指标和输出粒度；缺少会影响正确性的条件时只询问关键缺口。
2. 优先使用项目已有 Fetcher、SQL 工具、数据合同和证据包；先读工具说明或 manifest，不扫描无关目录。
3. 选择一个主数据源；只有主源缺测、冲突或用户明确要求交叉核验时，才增加第二个来源。
4. 使用必要字段、有限行数和明确过滤条件查询；记录来源表、批次、时间范围、过滤条件和缺测情况。
5. 返回简短事实表或证据卡片，并区分原始事实、计算结果和研判解释。

## 效率约束

- 默认单轮查询，最多两个来源；不默认分页穷举、历史全量扫描或重复核验。
- 先返回当前问题所需结果；不要为了“完整”补充无关指标。
- 数据不足时说明缺口和影响；不要用相邻来源、旧批次或推算值静默补齐。
- 只有用户明确要求、来源冲突或结论需要额外证据时，才升级为扩展查询，并先说明将增加的范围。

## 交付自查

- 是否写明来源、批次或时间范围、筛选条件和单位。
- 是否保留了缺测、覆盖不足和口径差异。
- 是否把相关性、排序或筛查分数误写成贡献率、责任或确定归因。
- 是否能由记录的条件复现核心结果。
