# 环境证据文档抽取

## 适用边界

用于报告模板、监测通报、批复、技术文件、表格和 PDF/DOCX 证据的定向抽取。输出服务于事实核对、报告组装和证据回溯，不把文档转换本身当成分析结论。

## 默认流程

1. 先确认文件路径、文档类型、目标页或目标字段；已有 manifest 或证据包时优先读取其索引。
2. 只抽取当前问题需要的章节、表格、页码、坐标或字段；保留原文单位、日期、来源和页码。
3. 扫描件或版面敏感内容需要 OCR/版面解析时才启用相应能力，并标注识别状态。
4. 对抽取结果做最小核对：标题、日期、单位、行列关系和关键数字；疑似 OCR 错误保留原文并标记待核实。
5. 输出短证据片段或结构化字段，附文件、页码或表格定位，不直接生成未经核验的业务结论。

## 效率约束

- 默认最多处理两份文档或两个目标章节；不默认全文批量 OCR。
- 已有结构化证据时不回读原始文档；只有字段缺失、冲突或用户要求查看原文时才补读。
- 不为获得“完整背景”抽取无关页面，不将 OCR 结果直接当作确定事实。
- 文档解析失败时说明失败位置和影响，保留待核实事项。

## 交付自查

- 是否保留文件名、页码或表格定位、日期和单位。
- 是否区分原文、OCR 结果、结构化字段和 Agent 解释。
- 是否检查了关键数字、表头、合并单元格和跨页内容。
