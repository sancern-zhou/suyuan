# 空间分析

## 适用范围

本技能仅在专家模式或报告模式中按需使用，适用于：

- 站点与行政区、乡镇、企业或网格的点面匹配；
- 最近站点、最近企业和距离排序；
- 行政区聚合、空间筛选、裁剪和 GeoJSON 结果导出；
- 需要表格化空间连接的空间分布报告。

底层优先复用现有 `spatial_analysis` 工具和 `backend/app/tools/spatial/geopandas_analysis.py`，地图展示和报告图表继续使用现有资产与图表流程。

## 执行边界

1. 先确认坐标字段、坐标系、空间范围、时间口径和数据来源。
2. 点面连接前检查两侧 CRS；距离、面积和缓冲区计算必须使用合适的投影坐标系，不能直接在经纬度上计算米制结果。
3. 保留输入要素数、匹配数、未匹配数、CRS、空间谓词和筛选条件。
4. 几何无效、CRS 缺失或坐标越界时停止并报告，不自动猜测坐标系。
5. 空间相邻、重叠或最近关系只能作为空间线索，不能直接写成污染来源、责任归属或因果结论。
6. 已有专用空间工具或固定报告图型优先复用，不在 `execute_python` 中重复实现同一流程。

## 不适用场景

普通表格统计、无需几何关系的站点查询、平台已有空间统计、地图展示本身，以及没有明确 CRS 的临时坐标数据，不触发本技能。
