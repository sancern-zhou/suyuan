# 统计分析

## 适用范围

本技能仅在专家模式或报告模式中按需使用，适用于：

- 趋势斜率、显著性和置信区间；
- 污染物与气象因子的相关或回归分析；
- 两组或多组数据的比较、非参数检验和效应量；
- 规则时间序列的 STL 季节分解和诊断图。

底层优先复用 `backend/app/tools/analysis/statsmodels_analysis.py` 中已有的单变量趋势、单变量 OLS（可选 HC3）和 STL 封装；多元回归、Mann-Kendall、Theil-Sen、Mann-Whitney、Cliff's delta、块 bootstrap 等方法目前由 `execute_python` 按本技能边界显式实现，不能假定该模块已经提供。执行和绘图通过 `execute_python`、`create_business_chart` 及现有报告图表规范完成。

## 执行边界

1. 先确认指标、时间窗口、空间范围、统计口径、单位和有效样本条件。
2. 保留原始样本数、有效样本数、缺失值处理和数据变换记录。
3. 趋势至少需要 3 个有效观测，回归至少需要 5 个；样本不足时返回证据不足。
4. 选择检验前检查独立性、分布、方差和时间序列特征；不满足假设时使用稳健或非参数方法并说明原因。
5. 输出方法、样本数、效应量或系数、置信区间、显著性、拟合优度和限制说明。
6. 相关、回归和显著性只能表述为统计关系或共变线索，不能写成确定因果、来源贡献或治理效果证明。
7. 官方月度、季度、年度统计和官方预报继续使用平台数据，不由模型从小时数据替代推算。
8. 不默认执行 Bayesian、自动预测、自动变量筛选或复杂功效分析；只有用户明确要求且数据条件满足时才单独评估。

## 报告和图表

- 正式报告静态图优先使用 `execute_python`，已支持的业务图型使用 `create_business_chart`。
- 继续使用统一字体、图例、单位、系列色、DPI 和导出检查。
- 图表标注统计方法、有效样本数和置信带含义；不要只给 p 值。
- 箱线图默认用横轴分组标签表达组名，不要为没有语义系列的箱体调用空图例。确需图例时必须显式构造 `handles` 和 `labels`，例如 `ax.legend(handles=handles, labels=labels, ...)`，再交给统一的下方图例布局接口。
- 统计结果进入报告前，与原始查询结果和数据口径交叉核对。

## 不适用场景

普通查询、排序、汇总、排名、平台已有统计报表，以及环境管理中不需要统计检验的快速问答，不触发本技能。
