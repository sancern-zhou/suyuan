# 分类型诊断手册（广东）

按现象选择最接近的一节，最多读取两节。每节的排查顺序都是"先证据、后判断"；没有证据的原因只能列为待现场排除项。

## 数据断数或数据缺失

适用：站点小时数据连续缺失、断续缺数、平台无数据但设备在线。

1. 用站点运行日报确认缺数起止、连续小时数和是否已恢复、回补。
2. 查告警通知中该站的"站点断数"记录，核对首次通知时间与缺数开始时间。
3. 查故障工单：是否有对应的网络、通信、数采、停电类故障单，处置时间是否覆盖缺口。
4. 查设备生命周期：缺数前后是否有停用、启用、信息更新事件。
5. 用小时数据核对恢复后的数据形态；恢复后仍有异常值时另起诊断，不并入断数原因。

## 仪器数值异常（恒值、跳变、超量程）

适用：单污染物恒值、突变、超量程、与同城站点明显偏离。

1. 对比同站其他污染物、相邻时次和同城站点基线，判断是单参数还是多参数同向变化。
2. 查该时段是否有质控、校准、停运或现场检查工单；质控期间的数据不直接作为故障证据。
3. 查仪器状态、采样流量、站房温湿度和供电相关告警与设备事件。
4. 若只有单污染物异常且伴设备告警，提高仪器故障优先级；若多污染物同向变化且设备状态正常，保留真实污染可能并说明气象条件未知。
5. 建议现场复测、标准检查，恢复后用连续数据验证。

## 站房环境与供电异常

适用：站房温度/湿度异常、市电停电、空开跳闸、UPS 异常、雷雨天气跳闸。

1. 核对告警通知中的发生时间、持续时长和恢复时间。
2. 查故障工单的停运申请、维修处置和恢复记录。
3. 查设备生命周期中的停用/启用事件，确认设备是否整体断电。
4. 区分区域线路停电、站房内部故障和瞬时停电；无法区分时列入待现场核实。
5. 涉及供电安全时优先建议现场隔离和人工确认，不建议远程反控。

## 通信与数采异常

适用：网络信号异常、数采卡死、工控机卡死、数据不上传、平台离线。

1. 确认是单站、单设备还是多站同时异常，判断是否为区域网络问题。
2. 查该站网络设备、数采、工控机的近期故障工单与处置记录。
3. 查告警通知中"站点断数"与"仪器断数"的时间关系，判断是采集端还是传输端问题。
4. 查设备生命周期中的重启、信息更新事件。
5. 恢复后核对数据连续性和补传情况，补传缺口单独说明。

## 浓度超标或区域同步升高

适用：小时浓度超标、区域多站同步升高、站点趋势与城市不一致。

1. 先判断区域同步性：同城其他站点是否同向升高、周边城市是否同步。
2. 查气象条件（小时数据中的气象字段）对扩散条件的影响；没有气象数据时说明缺口，不推测。
3. 查该站是否有停运、质控、校准、设备故障；排除站点侧原因后再讨论污染过程。
4. 单站孤立超标且设备状态正常时，保留本地排放或局地污染可能，并建议结合周边源清单核查。
5. 结论只到"支持/不支持/数据不足"，不认定污染来源或责任。

## 平台误报警

适用：告警已触发但监测数据、设备状态和处置记录均正常。

1. 核对告警内容与实际数据是否一致，确认告警阈值、时间窗和数据质量标记。
2. 查同期是否有维护、校准、停运或网络抖动记录。
3. 查历史同类告警的处置结论，作为提高"误报"优先级的参考，但不能直接套用。
4. 若无法证明误报，保留"待现场核实"，不直接定性为平台问题。
