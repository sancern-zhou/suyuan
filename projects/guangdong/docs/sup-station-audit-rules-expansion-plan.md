# 组分站审核规则完善方案（依据《组分仪器工单规则》业务文档）

> 依据：业务方提供的《组分仪器工单规则.rar》（22 份仪器文档、239 张表单截图，2026-10-27）。
> 全部截图已逐张转录存档：`projects/guangdong/docs/sup-instrument-rules/`（6 个分册 + README）。
> 本方案对比文档要求与当前已实现的组分站审核规则（`backend/app/services/ops_audit/`），给出分期完善计划，待业务确认后实施。

## 一、结论概要

1. 文档覆盖 22 类仪器、约 90 种工单类型（周/双周/月/季/半年/年全周期）。当前已建档 22 个表单档案，但集中在"周质控/周检查"类，**月/季/半年/年周期的数值型表单基本未覆盖**。
2. 文档证实现有档案有 **3 处口径偏差需修正**（PANs 误差阈值、PANs 稳定性周期、OCEC 氦甲烷周期）。
3. 文档中大量规则是跨仪器复用的**表单族**（流量核查、温压核查、多点/标曲线性、年度维护检定报告、Excel 质控模板、异常需备注），做**通用规则族**一次开发可覆盖多数仪器。
4. 数据侧已有 4 张专用分表与表单族对应（`sup_rf_pm1monitorinspection`→PM1 巡检、`sup_rf_deviceflowcheck`→流量核查、`sup_rf_monitorinspection`→设备巡检、`sup_rf_ambienttemperature`→温压核查），2026-10-26 复盘确认周窗口 21 单中 17 单的表单只在分表——建档前必须先做 tag 盘点。

## 三、实施步骤（分期）

**阶段 0：数据盘点（前置，约半天，部署环境只读）**
- 按 `backend/scripts/sup_profile_probe.py` 思路对 5 张组分站表单表（`sup_rf_common` + 4 张分表）统计 ruleitemtag 分布、近 90 天行数、列填充率，产出"tag → 仪器/工单类型 → 数据量"对照表。
- 用文档表单标题与 tag 对照，确认每张表列语义；没有数据支撑的表单暂不建档（避免纯文档推列）。

**阶段 1：修正现有档案（约半天）**
- 落实 2.2 表中 6 项修正（PANs ±2%、PANs 稳定性/重复性年度口径、OCEC 氦甲烷半年双阈值、浊度计两个范围），业务确认后 `confirmed: true`。

**阶段 2：通用表单族（约 2-3 天，主要工作量在档案 YAML + 一条新通用规则）**
- 2a 年度检定报告：把 22 类仪器的年度维护检定 tag 按盘点结果批量建档（报告类附件要求+豁免关键词）。
- 2b 流量核查族：按 tag 建档（相对误差/示值误差复算+阈值）；AMA 标态换算、优泰"≤10% vs <±5%"等变体先转人工复核。
- 2c 温压核查族：建档 ±2℃/±1kPa + "无传感器/无显示值"备注豁免。
- 2d 多点/标曲线性族：按仪器建档 r/斜率/截距阈值。
- 2e 新增通用规则"异常勾选未备注"：勾选异常/未执行/不合格/× 且无备注 → 中严重度待复核（一处代码，全部表单受益）。

**阶段 3：Excel 质控模板解析（约 3-5 天，复用 O3 XLS 模式）**
- 顺序：重金属（判定规则最明确）→ 水溶性离子 → NMHC → VOCs/PTR-MS。
- 先做"文件存在+工作表在位+模板约定（-999、必填列）"软校验，再上数值判定（单点偏差、空白、R²、元素合格率）。

**阶段 4：试点与确认（持续 2-4 周）**
- 新规则 `enabled: true, confirmed: false` 试点，沿用现有口径（类型命中率过低不纳入、备注豁免、超范围有备注转人工）。
- 每周审核综述观察误报，月度回顾后逐项置 confirmed。

**本期不做**：照片"参数与图片一致"的全量视觉核验（沿用现有抽检+问题触发的水印试点模式，视觉核验另列扩展）；勾选类"正常/异常"逐项判断（仅做"异常未备注"联动）。

## 四、需业务确认的事项

1. 优泰甲烷月度流量：表内要求行"<±5%"与红字"≤10%"并存，以哪个为准？
2. PANs 稳定性/重复性：文档为年度工单，现有档案按周检 7 天，确认按文档改年度？
3. VOCs 站房温度：天虹 <30℃、禾信 <25℃、红字统一 25±5℃，按品牌区分还是统一？
4. 甲烷多点校准"各浓度点残差与理论浓度的比值应在±?%以内"原文数字不清，请给出限值。
5. 双周工单（甲醛双周、OCEC 双周空白单点）的及时性宽限天数口径。
6. 品牌差异（VOCs 4 品牌、水溶性离子 4 品牌、甲醛 2 品牌）：建议同一 tag 建档、品牌特有列缺失自动跳过，是否接受该口径？
7. "无传感器/无显示值/该设备无量程校准功能"等豁免，是否统一按备注关键词豁免（沿用现有豁免关键词机制）？
8. 年度检定报告豁免：文档显示全部要求预防性维护报告，确认无额外豁免类型（现有豁免关键词"无需送检/无需检定/不适用/无此项/未配置/停运"沿用）。

## 五、风险与依赖

- **tag 对照是最大前置**：多数表单只在分表（17/21 单），不盘点直接建档会列名错位、整单零命中。
- Excel 模板需从平台获取样例文件（模板说明文字已转录，格式受控但需实测解析）。
- 同一 tag 多品牌列语义可能不同，盘点时需按品牌抽样核对。
- 周期类判据（及时性）依赖质控计划数据（`sup_mtc_taskitem`）接入程度，无计划时沿用表单侧滞后口径。
