# 广东运维故障处置经验归纳

本文档从 guangdong_mart 同步库的故障工单（Fault 单，组分网 SupFault 单独说明）实测中归纳各类故障原因的典型处置动作与升级路径，用于指导故障诊断、派单与工单审核。故障原因的量级排名见 02-故障原因与诊断路径.md。

## 故障原因 → 典型处置动作与升级路径

### 供电类故障

- 站房空气开关跳闸：现场核查跳闸根因（常见根因：空调等站房辅助设备短路、空开自身故障、外部电压不稳定、周边施工挖断线路）→ 更换空气开关或合闸恢复供电 → 确认数据恢复上传。外部线路问题需联系区站/供电部门，处理周期明显更长。
- 雷雨天气跳闸：雷雨过后合闸恢复供电，确认设备重新启动、数据恢复上传。
- 站点出现瞬时停电：来电后确认数采与仪器是否自动恢复；瞬时停电后数采或仪器可能无法自动重连，需现场手动启动。
- 站房电路/电路辅助设备故障：常见根因为 UPS 故障、稳压器故障；现场重启或更换旁路线路恢复。
- 站点所在区域线路整修停电：计划性停电应提前关闭仪器；恢复供电后设备重新启动，缺失数据需补充上传，必要时发起数据回补单（DataMakeup）。

### 数采与计算机类故障

- 数采卡死：远程或现场重启数采仪/数采软件后恢复，并完成数据回补。
- 数采故障：硬件或软件级故障，远程重启失败后派现场检修或更换数采。
- 工控机卡死：重启工控机恢复；驱动异常需现场处理。
- 工控机故障/系统故障：操作系统级故障，需现场检修或重装。
- 设备死机：分析仪器死机（如臭氧仪），重启后恢复运行。

### 网络类故障

- 站点网络信号异常：先判断是否自动恢复；站房内重启路由器常可恢复；外部基站或线路故障需报修，由运营商/工程队检修，周期较长。需区分站房内设备故障与运营商链路故障。
- 站房网络设备故障：重启路由器 → 更换网卡或路由器。
- 异常天气、施工导致站点周边通信设备故障：典型场景为光缆被附近施工挖断，由运营商工程人员抢修，修复后确认数据报送恢复。

### 仪器类故障

- 设备故障：多为部件级更换（压力传感器、检测器底座、抽气泵等），更换后观察数据恢复正常。
- 设备数据异常：现场核查流量、加热温度等参数，必要时更换备机；区域性停电恢复供电后仪器有"数据稳定期"，期间数据暂不可用。
- 采样管路/采样系统出现异常：清洗采样总管/采样支管（进水、颗粒物沉积导致数据偏高或倒挂）后恢复。

### 运行状态与平台类记录（非设备损坏）

- 现场质控检查：例行质控作业（多点校准、清洁、停机维护）期间的数据中断属正常记录，审核时不应按故障处理。
- 站房申请停运：经省厅及省中心批复同意的站房停运（修缮等），属计划内状态记录，非设备故障。
- 平台误报警：现场核实仪器正常在线后，由平台运营商（旭诚）处理平台侧问题；工单必须注明核实结论，避免重复派单。
- 外部环境因素导致数据出现异常：异物掉落、周边施工等外因干扰，随外因消除恢复。
- 其他问题：无法归入明确类别的故障，需人工补充描述；处置方式个案各异，是审核中最需要人工判别的一类。

## 故障原因与设备关联特征

- 故障单的设备关联主要落在分析仪器（PM2.5、PM10、NO2、CO、O3、SO2）；数采仪、路由器、工控机等站房辅助设备在设备维度建档很少，此类故障的处理对象主要通过处理描述判断。
- "其他问题"类故障最集中在 PM2.5 与 PM10 仪器。

## 重复故障与升级排查

- 重复故障口径：同站同设备、本单创建前 30 天内存在其他故障单（mart_work_order_analysis.is_repeat_fault，仅 Fault 单有口径）。
- 高重复率原因：空气开关跳闸、数采卡死、站点网络信号异常——同一站点短期内反复发生，说明存在未根除的隐患（线路老化、设备不稳、链路质量差），应升级排查根本原因，而非重复同类处置。
- 站房申请停运、现场质控检查类记录的重复属状态延续，不按重复故障处理。

## 时效相对特征

- 可远程处置的故障（重启路由器、重启数采/工控机）修复明显快于需外部施工或报修的故障（线路整修、站房电路故障、运营商链路检修）。
- "其他问题"处理周期最长，因其需要人工判别与个案处理。
- 停电类故障的闭环以数据恢复上传为准。

## 组分网故障单（SupFault）处置特征

- 组分网故障单以专用仪器部件与测值异常为主：VOCs、重金属、PMT 组件冷堆、激光器、NDIR、MS 组分、进样/序列异常等，常需更换备机或返厂调试。
- 其处理描述多为系统自动状态（如 DeviceNormal），故障对象以工单标题与描述为准，不填报 alarm_reason。
