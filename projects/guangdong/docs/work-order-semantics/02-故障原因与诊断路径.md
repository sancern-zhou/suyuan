# 广东站点故障原因与诊断路径

本文档归纳广东省控站点运维故障单的高频故障原因（近一年实测）及其典型诊断路径，用于故障诊断与根因分析。

## 高频故障原因（按近一年工单量排序）

1. 其他问题：无法归入明确类别的故障，需人工补充描述。
2. 平台误报警：平台规则误报，现场核实设备无异常。
3. 站点网络信号异常：站点与平台间通信中断，数据无法上传。
4. 现场质控检查：例行质控作业期间产生的数据中断记录。
5. 站房申请停运：站房主动申请停运（检修、施工等）。
6. 站房空气开关跳闸：站房配电空开跳闸导致设备断电。
7. 站点所在区域线路整修停电：外部电网检修造成的计划外停电。
8. 数采卡死：数据采集仪死机，需重启恢复。
9. 设备故障：分析仪器本身故障，需维修或更换。
10. 雷雨天气跳闸：雷雨天气导致的配电跳闸。
11. 站房网络设备故障：路由器、交换机等网络设备故障。
12. 工控机卡死：站房工控机死机。
13. 数采故障：数据采集仪硬件或软件故障。
14. 工控机故障/系统故障：工控机操作系统级故障。
15. 站点出现瞬时停电：短时电压波动或瞬时断电。

## 故障类别与涉及设备

- 供电类故障（空气开关跳闸、线路整修停电、雷雨跳闸、瞬时停电）→ 涉及站房配电设施，恢复后数据自动恢复上传。
- 数采类故障（数采卡死、数采故障）→ 涉及数据采集仪（数采仪），常需远程或现场重启。
- 计算机类故障（工控机卡死、工控机故障/系统故障）→ 涉及站房工控机。
- 网络类故障（站点网络信号异常、站房网络设备故障）→ 涉及路由器/光猫/运营商链路。
- 仪器类故障（设备故障）→ 涉及具体分析仪器（如 PM10、PM2.5、SO2、NO2、O3、CO 监测仪）。

## 诊断路径要点

- 停电类故障优先核实供电恢复时间；数据恢复上传即视为闭环。
- 数采/工控机类故障先远程重启，失败再派现场。
- 网络类故障需区分站房内设备故障与运营商链路故障。
- 平台误报警需在工单中注明核实结论，避免重复派单。
- 同一站点短期内重复出现同类故障（如反复跳闸、反复断网），应升级排查根本原因。
