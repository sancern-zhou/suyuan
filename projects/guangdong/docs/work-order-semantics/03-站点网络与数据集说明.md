# 广东运维站点网络与工单数据集说明

## 站点网络

广东省空气质量监测网络由约 332 个站点组成（站点维度表口径），包括国控站点、省控站点与组分站（超级站成分监测网）。站点按地市/区域归属管理（region），站点信息包含站点编码、中文名称、经纬度、地址与站点类型。站点维度的中文名示例：从化天湖、南沙大稳。

组分站（组分网）单独成网，其巡检、现场检查、停运、故障、整改、校准与绩效审核使用 Sup 前缀的专属工单类型（SupCheck、SupSECCheck、SupPowerFailure、SupFault、SupWorkRectify、SupDeviceCalibrate、SupAchievement）。

## 站点运行监控口径

- 站点运行日报监控数据上传连续性：连续缺数超过 4 小时记为缺失事件，1-4 小时短时缺失不列入；数据恢复上传即停止跟进。
- 国控站点数据与省控站点数据来源不同通道，日报中分开列示。
- 部分候选编码站点在运状态待人工核实，未上传数据不自动等同于离线站点。

## 工单数据集结构（本地同步层）

- 工单主表：一行一张工单，含工单号、站点、设备、类型、状态、紧急程度、维护周期、创建/更新/完成/计划完成时间、超时标记与费用。
- 工单处理明细：一行一个流程步骤，含环节代码、处理人、起止时间、处理状态、故障原因与处理描述；是时效分析与流程链核查的依据。
- 附件索引：一行一条附件记录，按工单号关联，用于附件完整性核查；附件文件本体存于源系统。
- 站点维度表：站点名录与归属区域；设备维度表：站点设备构成与品牌型号。

## 审核要点（工单月度审核）

- 完整性：已完成工单的标题、内容、完成时间与处理人不得缺失。
- 时效：完成时间减创建时间应与维护周期匹配；计划完成时间超期需说明。
- 附件：质控类、巡检类工单应有关联表单附件。
- 流程链：处理明细的环节序列应符合工单类型对应工作流的定义。
