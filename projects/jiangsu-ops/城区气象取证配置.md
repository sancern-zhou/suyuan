# SOP-02 城区气象取证

气象来源为 Suncere `GetWeatherStationHour`。在后端项目环境文件中配置 `SUNCERE_WEATHER_TOKEN`，web 与 worker 使用同一环境文件。密钥不得提交仓库。

默认使用站点归属地级市的城区编码，不使用所属县市或随机区县站，不在小时之间切换气象站。编码目录来源：中国天气网 `https://www.weather.com.cn/data/city3jdata/provshi/10119.html` 及 `station/10119XX.html`。编码目录不保证 Suncere 在指定时间有数据；取证须同时核对 Suncere 的城市、站号和时间，空响应保留为缺测。

若接口供应方确认使用其他城区站号，在项目环境文件设置 JSON 对象 `JIANGSU_REVIEW_WEATHER_STATIONS`，键为城市名（可带“市”），值为实际城区气象站号。只填写已确认的城区站号。配置优先于默认目录；保留实际返回的站名、站号供追溯。

请求按不超过 12 个小时分段，413/500 分段降为单小时查询。接口密钥缺失、请求失败、缺小时和缺参数分别保留状态；异常值不填零。气象证据与监测取证窗口一致，仅为解释高低值的辅助证据，不单独决定数据剔除。

2026-09-07 实测：2026-09-01 12:00 和 2026-09-06 12:00 的接口响应成功，返回江苏 56 个区县站记录，未返回上述城区编码。该情况应显示城区站缺测，不能把区县数据当作城区数据。
