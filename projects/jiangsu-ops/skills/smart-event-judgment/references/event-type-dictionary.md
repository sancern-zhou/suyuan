# AI 事件类型字典

AI 研判完成后只能从本字典选择事件类型；系统生成阶段的主线索和初始名称不属于最终事件类型。

| 事件类型 | 主要判断方向 |
| --- | --- |
| 疑似雾炮喷淋 | 视频雾炮/洒水与 PM10、PM2.5 突降或异常波动同窗，并核对报备记录 |
| 疑似人员进入采样区干扰操作 | 人员进入、接触采样设施或遮挡采样口与数据异常、断数或报警同窗，并核对进站/维修/校准记录 |
| 疑似 XX 仪器故障 | 单仪器或单污染物恒值、离群、负值、无效值、断数、质控失败或仪器报警 |
| 疑似外界环境影响 | 超限或多站同步变化，且站内无仪器、供电、公共系统和站房环境异常，并有气象或外部作业支持 |
| 疑似站房停电 | 供电/UPS 报警与站点级断数、多仪器中断或多因子缺失同窗 |
| 疑似公共系统异常 | 数采网络、通讯、采样总管、零气/标气或配气报警与多仪器同步异常同窗 |
| 疑似站房环境影响 | 温湿度、空调、除湿或通风异常与多因子波动、仪器不稳同窗，并排除停电和公共系统异常 |
| 合规运维核查 | 进站、校准、维修、停电通知或喷淋洒水报备能够解释相关异常线索 |
| 数据异常待研判 | 异常数据真实存在，但缺少足以归因到人为、仪器、站房、公共系统或外界环境的证据 |
| 其他待人工复核 | 线索矛盾、可信度低或证据严重缺失，无法稳定选择其他类型 |

“疑似 XX 仪器故障”中的 XX 必须替换为具体仪器或污染物名称；不能输出未在证据中出现的对象。证据不足时选择“数据异常待研判”或“其他待人工复核”，并列出需要补充的证据。
