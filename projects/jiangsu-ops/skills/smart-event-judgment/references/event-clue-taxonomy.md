# 线索分类

设计文档 V3.0 将以下内容定义为线索来源。它们用于归并事件、建立证据链和辅助 AI 判断，不等于最终事件类型。

| 来源 | 示例标签 | 研判作用 |
| --- | --- | --- |
| 视频识别 | 雾炮喷淋、洒水冲洗、人员进入采样区、接触采样设施、遮挡采样口 | 标签由专业算法识别，直接采信为行为事实，不做重新识别；仅核验其对数据的影响，视频未接入时只能标记缺口 |
| 异常数据 | 数据突升、数据突降、离群、恒值、负值/无效值、逻辑异常 | 判断数据影响和异常模式 |
| 子站报警 | 供电/UPS、数采网络、公共系统、站房环境、具体仪器 | 判断设备、站房和链路证据 |
| 断数报警 | 站点级断数、多仪器断数、单仪器断数、数据延迟上传 | 判断影响范围和通信/供电线索 |
| 超限报警 | 浓度超限、仪器参数超限、预警超限 | 判断污染过程或设备参数风险 |
| 合规记录 | 进站、校准、维修、停电通知、喷淋洒水报备 | 解释线索并辅助判断合规运维，不直接定类 |

事件桶内全部标签必须保留。主线索只用于初始事件名称和优先取证；同名标签可以合并计数，不同来源标签必须并列分析。
