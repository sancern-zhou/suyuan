# 分类型诊断手册

## 仪器状态与超限告警

适用：`Instrument`、仪器状态超上下限、电压/温度/压力/流量异常。

1. 对齐告警内容中的设备、参数、实测值和限定值。
2. 查同时间站房告警和自动巡检，确认是瞬时、持续还是多设备共因。
3. 对照污染物小时序列判断数据是否同步突变、恒值、缺失或带质量标记。
4. 查近期同设备工单；复发时优先检查电源、传感器、接头、泵阀和耗材。
5. 建议现场复测、标准检查和恢复后连续数据验证，禁止直接建议远程反控。

## 监测数据突变或超标

适用：`peer_aggregate_deviation`、`persistent_peer_bias`、`trend_inconsistency`、浓度异常偏离。

1. 对比同站其他污染物、相邻时次、同城站点基线和质控标记。
2. 查质控任务，排除零点、跨度、标气或质控期间数据影响。
3. 查仪器状态、采样流量、站房温湿度与供电。
4. 若只有单污染物异常且伴设备告警，提高仪器故障优先级；若多污染物同向变化且设备状态正常，保留真实污染可能。
5. 验证标准包括质控通过、设备状态恢复及连续至少两个数据周期稳定。

## 恒值、断数与通信异常

适用：`flatline`、`data_stale`、断线、网络或采集器告警。

1. 判断最后有效时间、影响污染物范围和是否整站中断。
2. 整站同时停止时优先排查供电、网络、VPN/数采仪和平台链路；单仪器停止时优先排查仪器通信与采集通道。
3. 恒值时检查数采缓存、串口/协议状态和仪器实时显示，避免把低波动环境误判为冻结。
4. 工单必须写明补传/重传数据的合规边界，禁止虚构缺失值。
5. 恢复验证需覆盖实时上传、时间戳递增、状态码正常和平台端可见。

## 质控告警或质控失败

适用：校零、跨度、精密度、标气、质控任务失败或 `quality_flag`。

1. 先查质控历史，再用 `rId/rStart` 查任务状态和运行日志；需要时查质控监测曲线。
2. 分辨任务未启动、执行中断、响应不合格和平台记录失败。
3. 结合标气有效期/浓度、阀路、流量、响应时间、零点和跨度漂移判断。
4. 处置建议按“确认标准物质—检查气路—复做质控—校准/维修—数据审核”排序。
5. 未取得质控详情时不得断言分析仪校准失败。

## 供电、站房环境与安全告警

适用：停电、UPS、电压、温湿度、空调、烟感、水浸、门禁。

1. 判断是否同时影响多台设备与全部数据链路。
2. 优先列出人员安全、断电隔离、通风、防水和消防确认。
3. 恢复供电或环境后逐台确认设备自检、暖机和数据稳定，避免一次性重启全部设备。
4. 工单优先级依据安全风险、整站中断范围和持续时长提高。

## 采样与气路故障

适用：采样泵、流量、压力、管路、阀门、颗粒物切割器、泄漏或堵塞。

1. 结合流量/压力告警、污染物异常模式和自动巡检判断影响范围。
2. 检查采样头、管线、过滤件、泵阀、接头和冷凝水。
3. 涉及气路拆装时要求检漏；颗粒物设备同时检查切割器与流量校准。
4. 恢复验证包括流量/压力达标、检漏通过、质控通过和数据连续。

## 视频或人工巡检告警

适用：视频识别、人工巡检发现的人员、烟雾、水浸、门禁、设备外观异常。

1. 将视频/巡检告警视为观察事实，不从单帧推断设备内部根因。
2. 核对同时间设备告警、环境状态和监测数据影响。
3. 安全相关事件先建议现场复核和隔离，再安排设备诊断。
4. 若证据包不含图片或视频路径，明确要求审核者补充，不描述未看到的画面。
